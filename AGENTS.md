## Online game balance decisions — read this first
When a user asks to add, evaluate, or rebalance online units/spells, **first read `docs/UNIT_BALANCE_WORKFLOW_STANDARD.md`** and the actual `online-game.js` unit definitions. Use theory-first 1v1 calculations, compare same-cost card deployments (including qty), disclose first-hit/range/air/splash assumptions, and report suspicious strength/weakness to the user. The user decides whether combat power is fair once mobility, capture, range, air, splash, and tactics are considered. Never silently change user-approved values or treat an AI-proposed numeric adjustment as user-approved. Keep staged proposals separate from deployed gameplay values, and do not publish school Google Sites without user approval. For the current V1.2 candidate numbers, read `docs/BALANCE_REVISION_V12_USER_DECISIONS_2026-10-29.md`.
