# 小国戦線 III — FORTRESS FRONT（BOT対戦 α3）

横長の1画面で遊べる、近未来ファンタジーの陣取りカード戦略ゲームです。

**プレイURL:** https://8mahi8.github.io/shokoku-sensen/

GitHub Pagesが未設定の場合は、リポジトリの **Settings → Pages** から **Deploy from a branch / main / (root)** を選んで公開できます。画面が古い場合は再読み込みしてください。

## キャラデザイン更新（2026-10-13 / Art v1）

追加課金・有料生成API・外部画像・CDNを使わず、`v3-art.js` のHTML Canvas 2D描画によって**全8兵種のオリジナルキャラ**を実装しました。ゲーム本体はこれまでの戦闘バランスを変えず、外見・動作の見せ方を強化しています。

- 基本歩兵：ヘルメット・盾・槍・外套。歩行で足が動き、攻撃時に槍を突き出します。
- 偵察ライダー：ホバー走行車・スカーフ・槍。移動中に速度のエフェクト。
- 重装工兵：重装甲の作業スーツ・発光リアクター・ドリル/打撃アーム。
- 魔導射手：魔導フード・ローブ・光る弓と魔力弾。
- 制圧機兵：機械装甲・エネルギー砲。
- 守護ゴーレム：結晶核・巨体・独特の表情を持つ迎撃役。
- 浮遊ドローン：飛行翼・光るコア・羽ばたきアニメーション。
- 魔導重戦車：装甲走行体・長砲身・結晶動力。

8枚のカードにはそれぞれのキャラの**描画ポートレート**を表示。ゲーム開始画面または対戦中の**「✧ 図鑑」**から8体を大きく確認できます。図鑑を開いた間は準備カウント・戦闘タイマーともに停止し、閉じると再開します。

描画はプログラムによるベクター風イラストなので、**ユーザー環境での視認性と実機の負荷・画質は継続検証が必要**です。キャラのレアリティや強さはデザインによって変化しません。

## 今回の再設計

これまでの縦長3レーン・スクロール・4枚循環カードシステムを撤廃しました。戦場全体を横長1画面で表示します。前哨基地3つを奪い合い、最も前方にある自軍の前哨基地によって**全域共通の召喚ライン**が進みます。占領後は砦の中心よりも**少し敵陣側（フィールド上48座標）**まで召喚可能になります（赤軍側も左右対称）。途中の基地を取らず、敵陣奥だけ占領する「飛び地占領」も可能です。

カードは **8種類固定で全種類から常時選択**。基本歩兵は召喚回数無制限、他のキャラは試合全体の召喚回数が限られます。前哨基地を攻撃して占領できるのは、基本歩兵・偵察ライダー・重装工兵です。

## 遊び方

1. BOT難易度（練習／ふつう／むずかしい）を選んで試合を開始。
2. **開幕10秒は準備時間**。初期エネルギー8で部隊を自軍エリアに配置します。この間、両軍の兵士は移動・攻撃せず、資源も回復しません。BOTも同じ初期資源で配置しています。準備カウントは現実の10秒で、戦闘速度には左右されません。
3. 準備終了後に一斉進軍。キャラは自動で移動・戦闘します。敵首都を壊せば即勝利。
4. 左の青い召喚エリアにカードをドラッグして配置、またはカードを選んでフィールドをタップ。
5. 前哨基地のHPを占領可能ユニットが最後の一撃で0にすると所有者が変わり、HPが全回復。何度でも奪還できます。
6. 制限時間は**ゲーム内5分**。時間切れは首都のHP割合が多い方が勝利（同率は引き分け）。

マップは全体が表示されるため、カメラを動かす必要がありません。上部の速度ボタンで0.85倍／0.65倍／1倍を切り替えられます。PCでは1〜8キーでも兵種を選択可能。ゲームから離れて画面が隠れたときは、戦闘中に限り一時停止します。

## 初期カード（バランス調整中）

| キャラ | コスト | 召喚回数 | 役割 |
|---|---:|---:|---|
| 基本歩兵 | 2 | 無制限 | 2体召喚・前哨基地占領 |
| 偵察ライダー | 3 | 5 | 高速・前哨基地優先・占領 |
| 重装工兵 | 4 | 5 | 高耐久・前哨基地への攻撃が得意 |
| 魔導射手 | 3 | 8 | 2体召喚・対地／対空 |
| 制圧機兵 | 4 | 6 | 範囲攻撃・集団対策 |
| 守護ゴーレム | 4 | 5 | 迎撃・防衛 |
| 浮遊ドローン | 4 | 5 | 2体召喚・飛行 |
| 魔導重戦車 | 6 | 3 | 高耐久・前線突破 |

カードを使うと残りの召喚回数が減りますが、手札待ちや山札の循環はありません。資源は序盤0.25/秒、中盤0.36/秒、終盤0.53/秒、最終盤0.70/秒へ段階的に加速します。練習BOTはプレイヤーより資源回復と判断頻度を抑えています。
