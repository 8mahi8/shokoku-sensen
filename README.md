# 小国戦線 — BOT戦 α1

横画面iPadで友達と遊ぶことを目指す、近未来の2Dリアルタイム戦略ゲーム。

**現在はオフラインBOT戦の初期試作**です。オンライン通信・Firebase・Google Sitesはまだ接続していません。自作のキャラクター・UIを使い、外部ライブラリなしのHTML Canvas 2Dで動作します。

## 試す方法

### GitHub Pagesで公開
1. リポジトリの **Settings → Pages** を開く。
2. **Build and deployment** の **Source** を **Deploy from a branch** にする。
3. **Branch** は `main`、フォルダは `/(root)` を指定し **Save**。
4. 公開の完了を画面で確認してから `https://8mahi8.github.io/shokoku-sensen/` を開く。GitHub Pages設定画面に別のURLが示されたら、そのURLを優先してください。

ローカルの場合は `index.html` をブラウザで開けます。

## α1 の遊び方
- 自軍は青（下側）、敵BOTは赤（上側）。マップは縦長、端末は横向きを想定。
- **部隊召喚**：カードを選び、自軍領土をタップ。資源を消費して**即座に召喚**。戦闘と進軍は自動。
- **建築**：建物を選び、所有領土の空いているグリッドへ配置。完成まで数秒かかります。
- **軍事施設**：兵舎は盾兵・対戦車兵・偵察兵、車両工場は装甲車・戦車、砲兵施設は迫撃砲を**完成時に一括解放**。
- **経済**：発電所を完成させると資源獲得量が増えます。開始時の資源収入は毎秒1.2。建物の効果は完成後のみ。
- **領土**：中央の6区画。隣接して到達可能な区画に味方のみが約5秒残ると占領できます。占領地でも召喚と建築が可能です。
- **作戦命令**：右端で全方面・左・中央・右を指定し、「進軍」「領土制圧」「防衛」「撤退」を選びます。まずは方面単位の命令のみです。
- **カメラ**：画面の空いた場所をドラッグして移動、ミニマップをタップしてジャンプ、「基地へ」で戻る。＋/－やホイール、ピンチでズーム。
- **勝敗**：敵首都を壊せば即勝利。6分経過時は破壊した固定砦の数、その次に首都・砦の損傷合計で勝敗判定。
