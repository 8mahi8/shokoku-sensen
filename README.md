## 基本操作

- **カード召喚**：画面下のカードをドラッグして、青い召喚範囲で離す。カードをタップして選択 → 戦場をタップする方法でも出せます。
- **手札循環**：8枚固定デッキ／手札4枚。使ったカードは山札の後ろに回り、次のカードが補充されます。今回はカード収集・デッキ編集機能なし。
- **資源**：最大10。通常対戦は毎秒0.65、最後の120秒は毎秒1.3。練習BOTではさらにゆっくり毎秒0.5（終盤1.0）。BOTも同じ手札・資源ルールで戦います。
- **カメラ**：戦場を上下スワイプして移動。3レーンは横方向に常時見えます。左上ミニマップをタップしてジャンプ。「自軍へ」「中央へ」ボタンも使えます。PCではホイールでも上下に移動できます。
- **難易度**：初期設定は「練習BOT」。BOTの出撃が遅く、最初の考える時間も長め。「ふつう」「むずかしい」へいつでも再戦で切り替えられます。
- **速度**：上部の「速度」ボタンで0.75倍（初期設定）→0.50倍→1.00倍に切り替え。カメラ操作はこの速度設定に影響されません。
- **停止・再開**：右上の一時停止。端末を離れて画面が非表示になった時も自動で一時停止します。

## ルール

1. 味方は青（画面下側）、敵は赤（上側）。
2. 兵士はカードで直接召喚され、自動で進軍・交戦します。建築・軍事研究・細かな作戦命令は廃止しました。
3. マップには **前哨基地4つ** と **首都2つ** があります。前哨基地は最初中立です。
4. 前哨基地のHPを**占領可能なキャラ**で0にすると、最後の一撃を与えた陣営のものになります。占領時HPは回復し、何度でも奪い返せます。
5. もっとも敵陣側にある**自軍所有の前哨基地**で、**3レーン共通の召喚ライン**が前進します。途中の基地を取っていなくても前線を飛び越えて奇襲できます。敵に奪われると召喚範囲も後退します。
6. 首都HPを0にしたら即勝利。**制限時間7分**で決着しない場合、首都の残りHP割合の多い方が勝利。同割合は引き分け。

## 練習モードのねらい

初回のBOT戦が忙しすぎるという試遊フィードバックを受け、練習BOTの行動回数を減らし、開始までに余裕を持たせ、ゲーム全体の進行速度を選べるようにしました。カード戦闘・前哨基地・3レーン自体のルールは変更していません。これでも忙しい場合は、プレイ中に忙しかった瞬間を確認してゲームの構造から再調整する予定です。

## テンポ調整（α2.1）

試遊でゲーム全体が速すぎたため、キャラ移動速度を以前の約52%に、攻撃間隔を約1.45倍に調整。攻撃ダメージを少し低下させ、首都HPは4500、前哨基地HPは14に変更しました。資源回復も減らして連続召喚の頻度を抑えています。最初から遅い基本テンポにしており、さらにゆっくりなら画面上部の速度ボタンで0.5倍にできます。試合時間はゲーム内7分。これらはBOT戦で検証中の仮調整値です。
