## v4.2｜城塞巨兵ガルドを本編へ試験導入（2026-10-14）

- **既存の守護ゴーレムの外観だけを、横向きオリジナル2Dキャラ「ガルド B-04」に差し替え**。元のゴーレムと同じカード・召喚回数・HP・攻撃力・範囲攻撃・攻撃間隔・AIを使用。新しい兵種ではない。
- **66コマの画像キャッシュ**：ガルド独立試作のSVG原画（`gald-source.html`）から、ゲーム起動後に1回だけブラウザで透過アニメ画像を生成（待機8・歩行18・パンチ22・被弾8・撃破10）。通常の戦闘描画では画像の必要部分だけ描画し、SVGの骨格は毎フレーム再計算しない。
- **双方で使用**：プレイヤー／BOTのゴーレムは同じガルド。BOT側は進軍方向に反転し、色調を変えて敵軍と分かるように表示。
- **カード／図鑑**：画像キャッシュ生成完了後に、守護ゴーレムの肖像画を差し替え。ゲーム進行中でも通知イベントで更新。
- **フェイルセーフ**：未ロード中やキャッシュ生成が失敗した端末では、既存のCanvasゴーレムをそのまま表示。ゲームの戦闘・対戦には影響しない。画像キャッシュには初回ロード時間が必要。
- **検証**：デスクトップChromiumで独立元SVGの66コマを約2.7秒で生成できること、歩行・パンチ・被弾・撃破を含む描画10パターンで例外がないことを確認。旧エンジンとの同条件18試合で勝敗・城HP・終了時間が一致。GitHubコミット後の学校iPadでの性能・Safariでの外観は未検証。
- **本編の元デザイン保持**：従来のゴーレム描画コードはバックアップ兼読み込み失敗時の表示として残存。ほかの8兵種は変更なし。

## v4.0｜全9兵種のモーション強化（2026-10-13）

戦闘ルール、キャラ性能、BOT、デッキ、エネルギー、城HPを**一切変更せず**、Canvasによるアニメーションだけを追加・強化。

- **攻撃**：既存の戦闘クールダウンの終盤に照準・振りかぶりポーズを入れ、攻撃成立時に踏み込みや反動を表示。ダメージ発生のタイミングは変更なし。
- **キャラごとの動き**：歩兵とライダーは素早い踏み込み、工兵は重量感のある打撃、迎撃衛士は盾と剣の迎撃、守護ゴーレムは大きな腕の振り下ろし、重戦車は砲身の後退・車体の発射反動。射手、制圧機兵、ドローンも攻撃時のポーズを改善。
- **被弾**：短いのけぞりと既存の白フラッシュを組み合わせ、何が攻撃を受けたかを視認しやすくしました。大型は小さく、軽量ユニットは大きく反応します。
- **召喚**：小型・中型・大型ごとの出現速度を変え、リングの収束と浮き上がりを追加。新しい召喚演出は開戦前の準備フェーズでも表示します。
- **撃破**：即消滅だった兵士を短時間だけ視覚的に残し、重さに応じて傾きながらフェードアウト。判定や攻撃能力は、HPが0になった瞬間に従来どおり削除されます。表示用の残像数は上限34体に制限。
- **密集戦への配慮**：既存の過剰な常時発光は避け、攻撃の瞬間や大型の出撃時だけやや強いエフェクトを表示。召喚・撃破の描画は一時的で、ゲームロジックと切り離しています。
- **検証**：全9兵種×4状態のCanvas描画モック、およびゲーム画面の戦闘描画で例外が発生しないか確認。同一乱数シードの18試合で旧版と新モーション版の城HP・勝敗・決着時間が一致しました。実ブラウザ、スマートフォン、iPadにおける見た目と負荷は未確認のため試遊が必要です。

## v3.9｜BOTの手札戦略・大型召喚AI（2026-10-13）

- **ふつう／むずかしいの行動設計を刷新**。初期手札から偵察ライダー・魔導射手などの有用な非歩兵カードを使って手札を循環させ、ゴーレムや重戦車が引ける状態を作る。歩兵カードの連続召喚に頼らず、戦線の状況で部隊を選ぶ。
- **大型を召喚するための資源貯蓄**：大型カードが手札にある場合、7エネルギーまで貯めて召喚を狙う。城の近くに敵が迫った場合は貯蓄を中断し、制圧機兵・迎撃衛士・遠距離射手や歩兵で迎撃。大型の優先出撃位置は自軍の召喚ラインと戦況による。
- **大型の出撃通知**：「敵軍が○○を投入！」と画面内に表示。カメラ外で大型が出た場合も気づける。
- **難易度**：練習BOTの判断は従来どおり。ふつう／むずかしいは戦術判断を刷新。各難易度とも手札、資源回復、コスト、出撃回数、射程・攻撃力は既存ルールのまま（従来からある練習BOTの回復倍率を除く）。
- **模擬対戦（固定シード）**：練習・ふつう・むずかしい × 歩兵ラッシュ・混合編成・消極的防衛で各5試合、計45試合が正常終了。大型召喚ありの試合数は「ふつう」3/5（歩兵ラッシュ）、2/5（混合）、5/5（消極的防衛）、「むずかしい」0/5、3/5、5/5。同じ条件で大型投入が可能になった一方、短時間で決着する試合は大型を出す前に終了します。強さや適切さは実プレイヤーでの追加検証が必要です。

## v3.7｜範囲砲撃の確殺化・BOTの戦略改善（2026-10-13）

- **範囲砲撃**：ダメージを115→**125**に増加。HP116の無傷の基本歩兵も着弾すれば一撃で倒せます。コスト4、使用回数3、半径82、着弾予告1.3秒は維持。防護結界を受けている兵士には実ダメージが低下します。
- **むずかしいBOTの初期配置**：工兵4コストの代わりに、歩兵2コストを追加して左右の初動に分散。余った2コストをその後の迎撃に回せます。初期資源8は同じです。
- **前哨基地AI**：ふつう／むずかしいBOTの偵察ライダー・重装工兵は、遠すぎる基地へ直行せず、手前の未確保基地を優先して確保します。プレイヤー側の深追いする占領挙動には変更なし。
- **歩兵ラッシュへの対抗**：歩兵集団が近づき、制圧機兵を手札に持っている場合、すぐ近くに敵が迫るまでは歩兵を小出しにせず、必要な5コストを貯めます。BOTだけのステータス強化・エネルギー追加はなし。
- **模擬対戦**：複数の固定シードで、歩兵連続召喚型と複合部隊型のプレイヤー操作スクリプトを対戦させ、従来より対集団防衛が改善することを確認。ただし実際の人間のプレイ・勝率を保証するものではなく、実機での再検証は必要です。

## v3.5｜BOT戦術・難易度改善（2026-10-13）

- 初期難易度を**練習から「ふつう」**に変更。練習も引き続き選択できます。

## 今回の再設計

これまでの縦長3レーンを撤廃し、広い横長戦場をカメラで移動して遊ぶ形式に再設計しました。前哨基地3つを奪い合い、最も前方にある自軍の前哨基地によって**全域共通の召喚ライン**が進みます。占領後は砦の中心よりも**少し敵陣側（フィールド上48座標）**まで召喚可能になります（赤軍側も左右対称）。途中の基地を取らず、敵陣奥だけ占領する「飛び地占領」も可能です。

基本歩兵はいつでも召喚可能で回数無制限。残りの兵種とスペルは4枚循環手札から使用し、それぞれ回数制限があります。前哨基地を攻撃して占領できるのは、基本歩兵・偵察ライダー・重装工兵です。

## 遊び方

1. BOT難易度（練習／ふつう／むずかしい）を選んで試合を開始。
2. **開幕10秒は準備時間**。初期エネルギー8で部隊を自軍エリアに配置します。この間、両軍の兵士は移動・攻撃せず、資源も回復しません。BOTも同じ初期資源で配置しています。準備カウントは現実の10秒で、戦闘速度には左右されません。
3. 準備終了後に一斉進軍。キャラは自動で移動・戦闘します。敵首都を壊せば即勝利。
4. 手札をタップで選択し、青い召喚エリアをタップして兵種を召喚。スペルは全域でタップ発動。戦場をスワイプするとカメラ移動のみで、召喚しません。
5. 前哨基地のHPを占領可能ユニットが最後の一撃で0にすると所有者が変わり、HPが全回復。何度でも奪還できます。
6. 制限時間は**ゲーム内5分**。時間切れは首都のHP割合が多い方が勝利（同率は引き分け）。

マップ全体は一度に表示されず、戦場をスワイプして移動します。上部の速度ボタンで0.85倍／0.65倍／1倍を切り替えられます。PCでは1キーで基本歩兵、2〜5キーで表示中の4枚の手札を選択可能。ゲームから離れて画面が隠れたときは、戦闘中に限り一時停止します。
