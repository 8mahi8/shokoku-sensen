# 小国戦線III｜任意の匿名対戦記録・まとめてBOT研究 v0.1（2026-10-20）

## 何を作るか・作らないか

- **目的**：学校の仲間と実際にプレイした「対人1vs1」と「BOTとの1人プレイ」の記録を、後日開発者がまとめて分析できる状態にする。
- **今はしない**：自動でAIを再学習・更新、クラウドへの対戦ログ送信、リプレイ画面、ユーザー登録、ランキング、個人の行動評価、チャット保存。
- **本番に導入しない**：本PRは開発版の実装・検証。公開の `main`、Google Sites、Firebase RTDB Rules・設定は本人の承認があるまで変更しない。

## 同意と安全

- 初期状態はOFFで、自動録画・送信なし。
- 1人プレイの場合、本人が端末内のチェックをONにした試合だけ記録。
- 対人1vs1では、ホストとゲストが**それぞれ**ロビーでチェックをONにした場合に限り、ホストのブラウザだけで記録する。Firebaseの既存 `players/host`/`players/guest` に対戦同意boolean `researchConsent` のみ追加する。ゲーム本体の対戦スナップショット・コマンドへ研究データを混入させない。
- 途中の記録停止を双方の端末から実行できる。撤回時はその試合の未確定メモリ記録を破棄し、引き続き対戦自体は可能。
- 同意フラグ以外の研究ログはFirebaseへ送信しない。参加者名、端末ID、IPアドレス、ルーム番号、実日時、発言内容を保存しない。
- **対戦中の記録は利用者の事前同意が必要**。記録やファイル共有を他人に強制しない。

## 記録するもの

- バージョン付きスキーマ `schema:1`。モード `solo`（対人対BOT）／`online`（対人またはゲストBOT、**人間操作か否かは現版では判別しない**）。
- ホスト権威のゲームコードで実際に受理された合法カード使用：ゲーム経過秒、準備中/戦闘中、陣営、カード種類・使用座標、事前資源、自軍手札4枚まで。
- 8秒に1回の世界スナップショット：両軍のエネルギー、城HP、砦所有状態、最大180体の現存ユニットの種類・座標・HP。試合開始と終了も取得。全手の操作位置の詳細な時間差を研究できるが、8秒刻みでは戦闘途中の全状態は復元できない。
- 終局：勝者陣営、ゲーム経過、双方城HP、砦状態。表示名や接続情報なし。
- バッチ上限：最新8試合、1試合最大500合法カード使用・80サンプル。超過を`overflow:true`と記録し、完全データと取り違えない。

## 保存・書き出し

- まず端末の `localStorage` に、**同意済み・終了済み**の匿名試合だけ保存（通信とは完全に別）。
- Google Sites埋込・Safariのプライバシー制限でlocalStorageやダウンロードが失敗することがある。安全に失敗し、同じ開いているページ内に記録を残す。ダウンロードできなければ「JSONコピー」または表示テキストからの手動コピーで救済する。
- 再読み込みで消える可能性があるため**対戦後は必ずJSONを書き出す**。8試合を超えると古いデータから消える。無断の自動アップロードやGoogle Driveへの代理保存はしない。
- 収集ファイルを後日明示的にこちらへ渡してもらえば、複数端末から集めたJSONを統合し、旧BOT研究と比較できる。

## 学習・評価に使う前に

1. 最初はユーザーと友達の負担を増やさない研究記録だけにする。**自動学習はしない**。
2. `solo` と `online` を分ける。現バージョンの `online` には赤軍ゲストがBOT操作に切替えた試合も混ざるので、人間vs人間と自動的に断定しない。ゲーム外で確認した対戦相手種別を別記録で管理するか、後の版で明示的な匿名ラベルを追加する。
3. 収集ログは勝者の行動を無条件に「正解」としない。初期デッキ・先後・戦況・練度差による偏りを評価し、勝ち負けだけで因果を断定しない。
4. 既存研究 `docs/BOT_RESEARCH_SYNTHESIS_20261020.md` を参照。まず手札/資源の有効選択肢があった局面、砦を守る・捨てる判断、城防衛と攻城の両立、ユニット投入後の実際の戦果をまとめて確認する。
5. 実BOTへ反映する際は、記録に使った試合データと、未使用の独立テスト（旧BOT＋複数対戦型＋人間）を分ける。評価済み試合で都合よく調整しない。

## 必須回帰

- `tests/online-research-log.cjs`：初期OFF、双方同意、拒否/撤回時の記録破棄、匿名フィールド、保存拒否時のメモリフォールバック、削除。
- `tests/online-research-browser.cjs`：Chromium・WebKit・Sites配布HTMLで1人プレイの合法アクション／完了試合／書き出し／再読込／削除。
- `tests/online-smoke.cjs` と release gate：`online-net.js`、`online-game.js`、`online-research.js` と2つの配布HTMLが完全一致、オンライン通信／埋込／戦闘性能の既存回帰に悪影響を与えない。
- 最終的な学校iPad Safari＋実Google Sitesでの手動の書き出し／コピーは**未検証**。公式ブラウザのテストと区別する。

### 既知の限界

- 初版のオンラインログはホストのみ。ゲスト画面の描画遅延・実際のタッチ軌跡・誤操作は記録しない。
- 勝者だけの学習ではカード強化や地形偏りなどを誤学習する。研究用途に限り、行動ログから弱点と反例を抽出する。
- 現時点でファイルが貯まるだけで、BOTは自動的に強くならない。
