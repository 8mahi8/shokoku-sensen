## 1. まず数式で可視化する

前提：**1ユニット対1ユニット**、互いに合法的に攻撃できる、すでに互いの射程内で停止、初撃時刻0秒、攻撃タイミングが重なれば同時処理。防護スペルなし、スキルなし、地形なし、射程差なし、移動なし、範囲攻撃による第二対象なし。現行の`hitAir`（対空攻撃可否）は合法性として考慮する。

- `hitsToKill = ceil(相手HP / 自分の攻撃力)`
- `timeToKill = (hitsToKill - 1) * 攻撃間隔`（**初撃が0秒なので `hits * cooldown` としない**）
- 先に相手のHPを0以下にした側の勝利。勝者の残HPは、その時刻までに相手から受けた攻撃の合計を初期HPから引く。同時刻の攻撃は両方数える。
- **重要**：デッキカードから2体出る基本歩兵・魔導射手・ドローンは、この計算ではそれぞれ**1体分**。1カード対1カードとは違う。
- 実ゲームでは召喚時の初撃待ちが`rand(0,.65)`秒、射程・速度・召喚位置・距離・対象優先度・砦行動による寄り道、`guard`固定索敵円などがある。別評価が必要。
- 解析コード `node tests/online-balance-theory.cjs`：既存9体は**現行`online-game.js`のCLASSESを直接読み**、新5体は設計中の提案データとして読み、45対戦を算出。固定10ケースに理論値assertを設定。`--json`で全マトリクス取得。

### 参考：04 vs 偵察ライダーの計算内訳

- 双剣兵がライダー195HPを倒すのに`ceil(195/22)=9`発、決着まで`(9-1)*0.55=4.40秒`。
- ライダーは時刻0,1.05,2.10,3.15,4.20秒の**5発**を撃つ。合計`5*28=140`。
- 双剣兵の残りは`145-140=5HP`。
- これは余裕で勝つ相性ではない。距離・初撃待ちや他の兵の介入で戦闘の意味が変わる。

### 08の正面性能について

- `150/2.65≈56.6 DPS`。守護ゴーレムの`115/2.05≈56.1 DPS`とDPSは**ほぼ同じ**。
- しかし08はHP560で、ゴーレムHP1400の**40%**しかないため、真正面の殴り合いでは大敗する。
- **DPSが似ているから互角、という判断は間違い**。初撃時刻・必要攻撃回数・残HPを見れば明らか。
- 現行の共通ターゲット優先度は`castle2/fort0/unit2`のみ。大型を見つけても他兵より優先しないし、大型特効もない。

## 4. 新しい評価フレーム：計算→条件補正→必要な最小実証

| 段階 | 評価 | 判定方法 |
|---|---|---|
| **A：純粋な数値比較** | HP、攻撃、クールダウン、必要攻撃数、残りHP、相性表 | **全候補 vs 現行全ユニットを自動計算**。変更のたび再生成 |
| **B：カードとしてのコスト** | 召喚1回当たりの体数、消費エネルギー、カード使用回数、手札循環 | 1体の勝敗をそのまま1カード勝敗にしない。cost2の基本歩兵・射手は2体 |
| **C：攻撃できる条件** | 長射程の先制、移動時間、飛行に攻撃可能か、迎撃固定円、対象優先度、前哨基地の前進、スペル | 同射程内の理論値から差を分析し、簡単なモデルで計算する |
| **D：必要な場面だけ実証** | 範囲に複数巻き込まれる、砦取り合い、敵に進路を逸らされる、描画と通信 | 理論が破綻・曖昧になる**少数の固定シナリオ**。BOT大量試合や無目的な試遊でバランス決定をしない |
| **E：本人の感触** | 操作の楽しさ・直感的な分かりやすさ | 最後にGitHub Pagesで本人が試す。ゲーム公開は了承後のみ |

## 5. 数値から見えた調整優先順位

1. **04 双剣兵**：同コストの偵察ライダーへの理論勝利残HPが5。意図して僅差にするか、より安定した対近接火力にするかを決める。最初から高性能に上げず、まずカード2体の基本歩兵との対決モデルを作る。
2. **08 重撃砕兵**：汎用重撃として基礎モデルの相性が明瞭。現状の560HP／150攻撃／2.65秒をいきなり変更する理由はない。ただし実際の接近は速度17、射程44で、長射程相手の攻撃を受けることを別途計算。
3. **13 遠距離工兵**：正面戦闘の理論値は弱いが、砦HP12に対し`capture=1`×12回で占領する。射程95+砦当たり半径24で距離119未満から射撃可能。**長射程が本当に砦の攻防を変えるか**を数値検証する。
4. **24 迅速迎撃騎兵**：速度47の価値は静止した1v1では見えない。距離200離れた敵へ必要な移動時間と、索敵円外に出た敵を追わないルールを組み込んで検証。
5. **43 対地爆撃翼**：飛行に攻撃できない地上兵は反撃不能。そのため対空の有無がほぼ二値的な相性になる。`barrage`スペルは現行コード上、地上・飛行両方に125ダメージ（2回当たればHP230の爆撃翼は撃破可能）。**必ず対空の実効的選択肢があるかをデッキ構築面で検証**。迎撃衛士やゴーレムが空中敵に攻撃できないのは既存仕様であり、今回は勝手に変えない。

## 6. 今後の更新方針

- 本人の希望通り、HP・攻撃・クールダウンの変更候補は**まず数式と表**で比較し、どの1v1相性が変化するかを見る。闇雲に数値を調整しない。
- 対戦相性が際どいときは初撃のランダム待ち0〜0.65秒の位相差の範囲を数学的に調べる。
- 実装段階では既存`CLASSES`をデータ起点にし、新キャラも構造化データから計算を自動化する。共通AIをキャラごとに増殖させない。
- `tests/online-balance-theory.cjs`は分析用であり、戦闘コード・公開版への変更ではない。これがテストパスしても物理iPadの描画・通信・ゲーム体験は証明しない。
