# BOT候補のA/B学習試験 — train-only

\`develop\` 専用。カード性能、コスト、AIの通常判断は不変。QA以外で候補方策は呼ばれない。

- 候補A \`siegeWindow\`: 所有基地と占領可能部隊が揃い、守備急務がなく、資源7を使える場合、追加の偵察部隊より重戦車を優先。実際の通常 \`playCard\` でしか召喚しない。
- 候補B \`captureCoverage\`: 占領が必要かを調べるとき、既存の味方占領ユニットと次の前哨基地との距離300以内を評価。これまでの片方向半径に依存した判定の代替。
- 青赤、基地X反転、先手順序、固定乱数シードの組合せごとに、完全同条件の「通常戦術BOT vs 通常戦術BOT」と「候補BOT vs 通常戦術BOT」を実行。
- 訓練用シード 17/41/73/101/131/163 のみ。**holdout 2003/2017/2063 には触らない**。48候補試合×3方策、対照24試合、合計168試合。（第1回は2方策で120試合）
- 比較指標は勝敗ポイント差（同条件・同陣営の通常BOT対照からの改善）。大型召喚回数、基地攻略必要判定数、手札と資源、城HPは副次指標。
- 試合乱数はシーケンシャルなPRNGを共有するため、異なる行動による消費順の交絡は残る。改善確定とはしない。
- 実験結果が十分でなければ本番BOTには取り込まず、別案を試す。改善候補を採択するときのみ**一度だけ新規holdoutで独立検証**する。


## 第1回120試合の実測（#38869072691 PASS）

train シードのみで比較したところ、\`siegeWindow\` と \`captureCoverage\` はともに48比較の勝敗ポイント差 **0**。両候補とも大型召喚使用合計は **0**、対照でも **0**。判定基準の差はあっても、対戦上の実効差は検出できなかった。両候補は標準BOTへ不採用。

次の反証候補 \`reserveEarly\` は「前線に3体以上いて少なくとも1体は占領可能、城・基地が緊急攻撃を受けていない、敵の深い侵入がない、巨人カードが手札にある」という条件で資源2.5以上を7まで貯める。**その時点で召喚済み部隊が存在すること**を要求し、序盤の無条件な貯蔵を避ける。7到達時は実コストを支払って大型を配置。強さは未検証で、QA用のみ。

候補の勝敗だけでなく、7資源到達した判断回数・安全な大型準備機会・実際の大型使用数を比較する。保留用の未知シードは使わない。


## 第2回168試合の学習用比較（#38869393412）

候補 \`reserveEarly\` は **48比較中4件で敗北→勝利、悪化0件、改善差+4**。大型使用は対照0回→候補2回。ただし、勝敗改善4件はすべて**赤軍**で発生。青軍での改善は0件。元のカード・資源は一切変更していない。

\`siegeWindow\` と \`captureCoverage\` は引き続き差0のため不採用。安全な判断機会や資源7到達数も記録済み。候補はゲームに採用せず、新しい独立評価で反証する。

### 独立評価の事前登録

**結果を見る前に固定する**：候補 \`reserveEarly\` のみ。新しい未使用シード 3001, 3037, 3083, 3119, 3181, 3203。地形通常/反転×判断順序青先/赤先×候補陣営青/赤で48条件、ベースライン24試合。候補はこの検証前後で書き換えない。

事前の採用検討条件：
1. 対照に対する勝敗ポイント差 **+3以上**。
2. 悪化した比較が **最大1件**。
3. 青軍・赤軍それぞれの勝敗ポイント差が **0以上**。
4. 少なくとも **2種類のシード** で勝利改善が発生。

以上を満たさない限り、通常BOTへ変更を反映しない。満たしても対人実力やカードバランスの証明ではなく、回帰テストの確認が必要。


## 独立holdout評価結果 — 不採用（#38869657088）

2026-10-16、候補を \`reserveEarly\` に凍結してから、未使用シード 3001/3037/3083/3119/3181/3203 の24対照・48候補比較を実施。[Actions結果](https://github.com/8mahi8/shokoku-sensen/actions/runs/38869657088) は **SUCCESS**（テスト手順が完了したという意味で、方策改善の成功ではない）。

| 集計 | 条件比較 | 勝敗改善 | 悪化 | 差分 |
| --- | ---: | ---: | ---: | ---: |
| train / reserveEarly | 48 | 4 | 0 | **+4** |
| 未使用holdout / reserveEarly | 48 | 0 | 2 | **-2** |
| holdout 青軍 | 24 | 0 | 2 | -2 |
| holdout 赤軍 | 24 | 0 | 0 | 0 |

- holdoutの悪化2件はシード3001の青軍で発生。ほかの5シードは勝敗差が0。
- 大型召喚は、holdoutの同条件で**対照1回、候補8回**。使用回数増加は確認できたが、勝率改善は確認できなかった。
- 事前登録の「差+3以上、悪化1件以内、両軍非負、改善2シード以上」を満たさない。**候補は正式BOTへ不採用**。現行ゲームの通常戦術ロジックは変更していない。
- 学習時の+4だけで採用していたら誤った改善判断になった恐れがある。**holdout分離が実際に反証として機能した例**。
- 勝敗差には共通PRNGの消費順変化も含まれる。大型召喚が必ず敗因という因果的証明ではない。

### 次の研究条件

既に観察したシード3001等は**消費済み評価セット**。今後の新候補に独立した効力を見せたいときは、別の未使用シードを事前に固定する。

次の候補は大型に貯める回数そのものを増やすのではなく、**いつ貯めてよいか**（拠点支配、敵の接近、部隊の進軍進捗）を学習用ログで明示的に分類する。早すぎる貯蓄が防衛力を欠かす仮説を検証し、カード性能は引き続き凍結する。
