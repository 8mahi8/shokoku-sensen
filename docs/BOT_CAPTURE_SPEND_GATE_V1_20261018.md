# 小国戦線III｜公開資源による低コスト占領ガード（QA限定）

2026-10-18。従来の`captureTempoInfantry`は既知120比較条件で勝敗改善10、悪化10、城HP平均-107.98。特に`banker`（資源貯蓄）相手では改善1・悪化6、自城HP平均-739.5だった。占領時間を伸ばしても7コスト反撃への備えを損なう可能性がある。

新候補`captureSpendGate`では既存の早期捕獲用歩兵投入の条件に加えて、以下を必須にする：

1. 自分の資源は2以上4未満。手札の最安価格は5以下で、購入可能カードは0枚・最安まで少なくとも3秒。
2. 敵の**公開カード投入履歴と既知回復率から再構成した**資源が4未満、7コストへの回復も9秒より先。
3. 敵の大型ユニットが一体も可視でない。捕獲予定基地/召喚線付近に敵がいる場合も見送る。
4. 初期130秒間、未確保基地への占領部隊がいない場合のみ。既存の砲撃・対空・緊急防御は先に処理する。

この施策は手札循環と相手の高額カードへの反撃余力を確保するための**仮説**。本番BOT、公開main、カード・回復・ユニット性能は変更しない。敵の非公開手札や真の資源は見ない。

固定局面・既知17/41/73シード30比較ペア、および既知17/41/73/101/131/163シード120比較ペアで評価する。相手戦術別/陣営別の勝敗、基地保持時間、城HP、攻撃損害、使用カード、実発動数を記録。明確な再現性が得られなければ不採用、独立holdoutは消費しない。

### 採用検討の最低条件

1. 独立holdoutで勝敗差が**正**かつ改善ペア数が悪化ペア数を超える。
2. 自城HP平均が悪化しない。BLUE/REDどちらも極端な悪化がない。
3. 特定相手の悪化が隠れていない。特に`banker`で再び負け越さない。

基準を満たしても実際の友人とのオンライン対戦の品質・強さは未検証なので、即座に通常BOTや公開mainに導入しない。

### 次回に向けた問題の再定義

単に2エネルギー歩兵を出すか控えるかの閾値探しを終了する。失敗の因果仮説は「4枚のカードを回転させない支出が、強い手札の利用・城の防衛・攻城能力を犠牲にした」こと。ただし現状は直接の因果分解がない。次は選択を変えず、**どの資源支出が次の有効カード購入を何秒遅らせたか**、前線・城HPの変化をイベント単位で観測する仕組みを優先する。短い単一効果の固定シナリオで識別できるまで、新たな自動戦術の連続追加は行わない。
