# 小国戦線III｜V10 攻城ドローンの機会費用ガード：QA実装・30Hz対照検証

2026-10-18。**develop QA-only**。今回の目的は、V7の実火力予測を使うドローン4資源予約が、合法的に可能だった砦確保・高価値ユニット・先行防衛を押し退ける問題を検証すること。現行の通常BOT・公開main・カード性能・通信は変更しない。

## 直前の実測に基づく設計
[機会損失監査 V9](BOT_CASTLE_BUDGET_OPPORTUNITY_AUDIT_V9_20261018.md) では既知6seed×両陣営×5相手スタイル×2設定、基準／V3／V7の360試合を比較。V7と通常防衛基準の全行動履歴が違ったのは120条件中2。具体例：
- seed41／青側rush：先行wardは双方実行したが、基準の84.3秒の射手はV7で出なかった。
- seed163／青側banker：基準の122.83秒重戦車（7コスト）をV7はドローン（4コスト）へ置換した。
- 7回の貯蓄開始のうち、待機期間に基準が何か支出したのは2回で、どちらも同時点では新戦術も同じ合法支出をしていた。機会費用が広範囲に発生したわけではなく、**介入自体が極端に少ない**。

## 新QA方策 `castleRaceChoice`
`online-game.js` と埋込配布物 `online-embed.html`／`online-ipad.html` のすべてに、V7と同じ既存城race・砦防衛・緊急支出の継承を維持する新QA variantを追加。V7の`castleRaceForce`自体は比較相手として残す。

V7の予測と可視攻勢群、現存砦・敵部隊、4資源・12秒等の既存条件は維持。その上で以下の合法支出が**その場ですでに可能**なら、新候補はドローン予約を見送って下流の通常BOT判断に戻す：
1. 手札に7資源級の重戦車／守護ゴーレムがあり、**実際にいま購入可能**。
2. 未占領の目標砦に向かう占領可能ユニットが実際に割り当てられておらず、ライダー／工兵が購入可能。
3. 味方所有砦に近づく敵がいるが、周囲に専用戦闘兵がなく、衛士／射手を現在購入可能。

前線占領担当は`getFort`で実際のAI対象を確認し、単なる近さを当てにしない。敵の非公開手札・真のエネルギー・未来の攻撃結果は参照しない。`choiceOpportunityVeto`と理由のカウンタをQA専用で記録する。

## 判定
- **通常BOTへは不採用。** V7モデルの研究価値を保つが、現行の城前ドローン資源予約路線を続けてしきい値調整しても頻度が不足する。
- `castleRaceForce` と `castleRaceChoice` はともに開発用QA variantとして保存。
- 次は、偵察ライダー／工兵が目的の砦に到着するまでの実測時間と、購入後の次の有効カード使用までの遅延を**選択を変えずに観測**する。特に攻城12秒予測とBOT支出判断の乖離だけに拘泥しない。
- 新しい候補は **頻出局面・具体的な戦果を先に確認** して設計する。新規シードを行き当たりばったりに使わない。QA学習と事前登録holdoutを分ける。
- 公開main、通常BOT、学校iPad向け対人オンラインには影響させない。
