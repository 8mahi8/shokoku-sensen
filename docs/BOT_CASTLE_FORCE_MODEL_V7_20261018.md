# 小国戦線III — 攻城12秒予測・戦力差 V7 実証記録
2026-10-18 | `develop`限定の研究・QA。公開main、通常BOTの意思決定、ユニット数値、ネットワークを変更していない。

## 目的
V6では視界・敵接触までの最短ETAで「交戦が起こるか」は予測できたが、実際の攻城ダメージ量の補正は敵城近くの守備兵の有無という単純なモデルに敗れた。そこで、「交戦の有無」と「交戦によって失われる攻城火力」を分離する。予測時点の味方攻勢部隊に対する敵の**現在HP・公開DPS**を取得し、実ダメージとの誤差を検証する。

## 実装・計測方法
- `online-game.js`, `online-embed.html`, `online-ipad.html` の同一戦闘エンジンに、localhost `?qa=1` で監査時のみ有効な`prePower`スナップショットを追加した。
- 現在の攻城候補部隊について`waveHp`, `alliedDps`, 敵城壁面230px以内の守備兵の現在`defenderHp`, `defenderDps`、味方の視界・前後関係・現在位置から接近条件を満たす`activeThreatHp`, `activeThreatDps`を集計。
- `prePower`は**予測時点の公開されているゲーム状態だけ**から計算。敵の未来の手札/召喚/行動、次の12秒の実際のターゲット時間、実ダメージは含まない。DPSは攻撃可能性の上限指標であり、相手が実際に狙うことを保証しない。
- 既存の元UID別攻城命中帰属と30Hz行動記録を維持。監査ON/OFFで初期手札・消費資源・使用カード・砦時間・試合結果が一致することを強制確認。

## 今回の結論
- 予測時点の可視敵味方HPに基づく**攻城予測モデルの改善は、事前登録した追加シードで再現できた**。V7は調査対象としてV6より有望。
- ただし1評価シードでは大きく悪化している。ゲーム内の攻撃標的・召喚のタイミング、隊列、実際の被弾、射程などを完全には説明していない。
- **この実験でBOTの勝率が向上したことは一切証明していない。** QAのモデル誤差を改善した段階であり、新しいカード召喚判断の損得は別実験が必要。
- したがって公開版・main・通常BOTに反映しない。次の研究では、予測モデルをBOTに実際に使わせるQA限定の選択肢を最小限で作り、*戦術変更の実ゲーム上の結果*を既知シード中心に測り、勝率・城HP・資源・砦保持を同時に検証する。
