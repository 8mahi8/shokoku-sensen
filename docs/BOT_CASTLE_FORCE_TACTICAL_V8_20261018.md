# 小国戦線III｜V7実測攻城力を使ったQA限定戦術・実戦評価 V8

2026-10-18。develop限定。通常BOTと公開mainは変更しない。

## 目的
V7の攻城12秒ダメージ予測は、既知6シードから学習・別の事前登録6シードで独立検証し、従来の守備兵あり/なしモデルよりMAEを7.58%改善した。しかし**予測誤差の改善は戦術の勝率改善を証明しない**。そこでQA用のドローン4資源貯蓄判断で、V3の楽観的な予測をV7の実測係数へ置き換える`castleRaceForce`ポリシーを評価した。

## 変更範囲
- `online-game.js`, `online-embed.html`, `online-ipad.html`にQA専用の`qaSiegeForceEstimate`を追加。対象は現在生存・HP50%以上の攻勢部隊、予測12秒の楽観火力、現存可視敵のHPと位置・射程・対空可否・前後関係。未来の手札やターゲット選択、未来の召喚・損害は使わない。
- 既知6シードで確定し、別の6シードで評価済みの**固定係数**だけを読む。敵城周辺の守備兵の有無×敵接近部隊HP/味方攻勢部隊HPの区分を使う。実行中に係数を更新しない。
- V3の「現存部隊で攻城しきれるなら追加ドローン不要」を、`12秒の推定実火力>=敵城HP*1.25`に変更。さらに敵前線HPが味方攻勢部隊HP以上で、推定火力も敵城の残HPの90%に届かないときは、脆いドローン増援のための資源貯蓄を取り消す（他のカードへの通常支出を継続）。
- 緊急防衛、砦防衛、先鋒の敵城到着ETA12秒以内、ドローン到着の遅延回避、資源4・最大12秒貯蓄・中断・再開抑止などは既存V3に準拠。
- `tests/online-bot-castle-race-force-v7.cjs`および独立workflowで固定シーン、既知6シード×両陣営×5対戦スタイル×2設定×3戦術＝**360実ゲーム**をPlaywright上で実行。勝敗・双方の城HP・砦維持時間・資源支出を比較。比較相手は`fortDefenseValue`（通常QA防衛基準）と`castleRaceValue`（V3）。

## 実装上の問題と是正
最初のQAコミットでは`castleRaceForce`を新しいドローン貯蓄分岐には登録したが、**V3が継承していた既往の城ダメージ履歴、城への攻め切り、砦・防衛分岐に含め忘れた**。これは実質的に複数の戦術を同時に変更しており、実験比較として不適切。最初の[Actions #39113574618](https://github.com/8mahi8/shokoku-sensen/actions/runs/39113574618)は360ゲームで勝敗悪化2と報告したが、これを「V7予測によって負けた」と解釈してはならない。

[修正コミット 160bc7d](https://github.com/8mahi8/shokoku-sensen/commit/160bc7d89487407316f1b9cfd5c46a65565e8114)で、城命中履歴の保存、城race/arrivalの判断、砦戦術・防衛の継承漏れをすべて補正したうえで**同じ条件を再実行**。

固定シーンでは、堅い敵の前線に対して不要なドローン貯蓄を取り消すこと、攻城終了間近の敵城に対してすでに十分な味方火力がある場合は余分な貯蓄をしないことを確認。ドローンが実際に到着可能なら資源4で正しく支出し、緊急防衛や砦喪失時は対応優先。

**正しい結論は「V7の攻城予測は実測改善したが、今回のドローン4資源貯蓄戦術では120条件で勝率改善が確認されなかった」。** 固定局面で戦術行動に差はあるが、多くの実試合では条件に入れず、恩恵は小さい。

## 決定
- **通常BOTへ不採用。** 公開main、カード、対戦安定性には変更なし。
- V7の予測モデルは研究資産として保持し、V8の実戦戦術はQA限定で残す。
- 次の研究は同じ閾値を何度もいじるのでなく、戦術選択に影響する**本当に頻出する局面**を定量化する。ドローンが法的召喚線から遠すぎる状態や、貯蓄を始める前に防衛が必要になる状態で、微小な火力補正に勝率を期待しない。新しい評価シードへ後付け最適化しない。
