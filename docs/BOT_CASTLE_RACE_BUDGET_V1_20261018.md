# 小国戦線III｜城ダメージレース前の4資源を確保するQA戦術

2026-10-18 develop専用。通常BOT・公開main・ユニットバランスは一切変更しない。

## なぜこの仮説か
前段の`castleRaceArrival`では有利レースの判断382回すべてで攻勢カードは手札にあるのに資源不足。291回は資源2未満、91回は2～4未満。そこで「城のダメージレースが成立する直前」に、味方攻勢部隊を見て、ドローン用4資源の短期確保を試す。

## 先に固定したルール（QA-only `castleRaceBudget`）
- 自軍の通常攻撃部隊（HP50%以上）が敵城から510px以内におり、近距離にHP45%以上の援軍がいる。
- 自軍砦を1個以上保持。自城HP850超。いま砦が攻撃されていないかつ自城から330px内に敵兵がいない。35秒から240秒の間だけ。
- ドローンを自分の手札から合法的に選べる。4資源までの回復予測が10.5秒以内。
- 条件が揃えば、最長12秒の短期資源保留。4資源到達後は合法的にドローンを出し、その後16秒の再判定抑制。
- 途中の緊急防衛、砦の喪失、部隊の壊滅、使用カード消失、期限切れでは資源保留を中断し、既存`fortDefenseValue`相当の判断に復帰する。
- 城同士の実ダメージレースが発生した後は従来`castleRaceArrival`の先着時間比較も継承。未来情報・不正な資源は使わない。

## 検証・撤退基準
固定場面：保留→4資源で合法ドローン召喚、緊急守備では衛士、砦喪失時のキャンセルを検証する。`tests/online-bot-castle-race-budget.cjs`で既知6シード×両軍×10条件×3政策（衛士優先／到着判定／事前確保）＝360フルゲーム比較。勝敗・自城HP・相手城被害・砦保持時間・資源消費・計画開始/中断/完成回数を記録。

改善が無い、または損害が出た場合は通常BOTへの採用なし。未使用holdoutは最終判定まで使用しない。
