# 小国戦線III｜攻城増援の限界価値・部隊生存 QA V3

2026-10-18。開発用ブランチdevelopのみ。通常BOT・公開mainには反映しない。旧`castleRaceBudgetGuarded`は対照戦術として保存。

## 経緯と事前の判断基準
先行の120対応条件×3政策の結果、12秒以内の城攻撃圏へ接近できる場合にだけ4資源を貯めるV2は勝敗の悪化をなくしたが、勝率改善0だった。これ以上の単純なしきい値緩和や既知seedへの勝率チューニングではなく、**増援が敵城へ到着する価値**を検査する。

- 可視味方攻勢部隊について公開クラスの攻撃力/攻撃間隔/射程/現在HPを使い、これから12秒で敵城に与えうるダメージの**楽観的な上限目安**を計算。敵城の残HPを十分上回り、敵兵による城近傍の迎撃がない場合、「すでに勝ち切りそう」として追加ドローン用の事前貯蓄を抑止する。
- 最前線の味方から165px以内で交戦可能な敵の公開火力から、簡単な最前線生存時間の目安を算出。約6秒未満で倒される計算なら、その部隊が攻城火力を維持するという前提が危ういため、貯蓄を開始せず防衛判断へ戻す。
- 増援ドローンが合法召喚線から射程まで到達する理想最短時間を比較し、先鋒より著しく遅ければ貯蓄は見送る。
- それ以外はV2の12秒以内の先鋒接近、緊急守備・砦脅威中断、ドローン4資源・12秒期限・16秒再判定抑制等を維持する。全て現在の可視状態・既知のユニット性能と既に起きた城命中のみ。相手の未来手札、未来召喚、勝敗結果は参照しない。

**重要な限界**: 上限火力モデルでは敵防衛、砦への寄り道、実際の標的選択、攻撃クールダウン、味方の壊滅などで過大評価しやすい。「増援不要」と正しく判定できる保証ではない。生存時間も敵の攻撃対象や迂回経路に依存する。これらは不確かな事前仮説として試す。
