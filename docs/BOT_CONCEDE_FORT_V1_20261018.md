# 小国戦線 III｜意図的な砦放棄・防衛費用の一時留保 v1

2026-10-18。ユーザーの「一つ砦を取られるとしても、無理に守るよりコストを貯めて召喚した方が展開がよくなる場合がある」という指摘を検証する。標準BOTでは`threatened`が検出されると直ちに`urgent=true`となり、適切な射手・衛士等が払えなければ最後に常設2コスト基本歩兵を出す。これは**砦を一時的に捨てる判断が防衛分岐に存在しない**ことのコード上の根拠。

## QAのみの反実仮説：`concedeFort`

- 所有砦が地上敵2体以上に攻められ、そばの防衛味方0、資源2以上4未満、**現在の手札に迎撃衛士（4コスト）がある**場合。
- 公開回復率に従えば4まで最大8秒。基地が落ちる可能性を許容し、**2コスト歩兵を出さず**11秒を期限として守備用資源を貯める。
- 資源が4に達したら、元の危険基地レーンに実際の正規召喚ルールで迎撃衛士を出す。出せなければ中断。
- 敵が城に接近（深部230px）・城への直接脅威・期限切れ・手札から衛士が消えた場合は計画を放棄し、通常防衛に戻す。連続発動を防ぐ12〜14秒のクールダウン。
- 優先範囲砲、対空・大型迎撃は**この選択の前**に従来どおり実行可能。戦術の試験はQAの`concedeFort`変種だけ。
- 敵の非公開手札や真のエネルギーは使わない。公開版`main`、通常BOT、バランス・当たり判定・通信は変えない。

**危険性**：迎撃衛士は設置地点に留まるため、落とした砦を取り返す能力はない。守るべき砦の判定は厳しく、基地喪失から敵の突破につながる場合はむしろ弱くなる。だから効果の検証は勝敗・自城HP・基地保持時間を同時に測る。固定局面と既知6シード、複数の相手スタイル、青赤を使い、一度は30組対照比較。学習で無理があれば見送り、見込みがあれば既知シードで追加再現確認し、独立シードは簡単には使わない。
