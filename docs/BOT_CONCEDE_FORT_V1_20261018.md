# 小国戦線 III｜意図的な砦放棄・防衛費用の一時留保 v1

2026-10-18。ユーザーの「一つ砦を取られるとしても、無理に守るよりコストを貯めて召喚した方が展開がよくなる場合がある」という指摘を検証する。標準BOTでは`threatened`が検出されると直ちに`urgent=true`となり、適切な射手・衛士等が払えなければ最後に常設2コスト基本歩兵を出す。これは**砦を一時的に捨てる判断が防衛分岐に存在しない**ことのコード上の根拠。

## QAのみの反実仮説：`concedeFort`

- 所有砦が地上敵2体以上に攻められ、そばの防衛味方0、資源2以上4未満、**現在の手札に迎撃衛士（4コスト）がある**場合。
- 公開回復率に従えば4まで最大8秒。基地が落ちる可能性を許容し、**2コスト歩兵を出さず**11秒を期限として守備用資源を貯める。
- 資源が4に達したら、元の危険基地レーンに実際の正規召喚ルールで迎撃衛士を出す。出せなければ中断。
- 敵が城に接近（深部230px）・城への直接脅威・期限切れ・手札から衛士が消えた場合は計画を放棄し、通常防衛に戻す。連続発動を防ぐ12〜14秒のクールダウン。
- 優先範囲砲、対空・大型迎撃は**この選択の前**に従来どおり実行可能。戦術の試験はQAの`concedeFort`変種だけ。
- 敵の非公開手札や真のエネルギーは使わない。公開版`main`、通常BOT、バランス・当たり判定・通信は変えない。

**危険性**：迎撃衛士は設置地点に留まるため、落とした砦を取り返す能力はない。守るべき砦の判定は厳しく、基地喪失から敵の突破につながる場合はむしろ弱くなる。だから効果の検証は勝敗・自城HP・基地保持時間を同時に測る。固定局面と既知6シード、複数の相手スタイル、青赤を使い、一度は30組対照比較。学習で無理があれば見送り、見込みがあれば既知シードで追加再現確認し、独立シードは簡単には使わない。

### 追加観測

「計画発動19回」という指標だけでは、実際に砦を落として待ったか、砦が持ちこたえたか分からない。次のテストから`resolvedAfterLoss`（砦が実際に失われた状態で計画が解決）、`resolvedWithoutLoss`、`waitWhileLost`、計画解決までの秒数、実際の反撃回数をQAに追加する。**これらの診断カウンターはBOTの選択に影響しない**。結果によって「意図的な放棄」と呼べる条件を検証する。

この結果から**本当に砦を一時的に失うことを許容した試合があった**と確認できる。一方、`resolvedAfterLoss`は「解決時にその砦の所有権を失っていた」という意味で、必ず奪還した証拠ではない。迎撃衛士は基本的にその場で防衛するユニットであり、すぐに占領を回復するとは限らない。平均解決時間は待機開始から資源確保、召喚または計画キャンセルまでの長さで、実際の中立化タイミングとは異なる。

### 設計上の結論

従来BOTの即時防衛には「捨てて耐える」という分岐がなかった。今回、城が危険なら中断し、砦が危険でも資源を温存して反撃する**実行可能な選択肢**を実装・検証した。これは次世代の戦術設計に残す。

しかし**勝敗+2/120ペアでは一般的な強化と結論できず**、RED側の平均城HP低下、balanced相手の城HP低下を無視できない。候補はQA限定で保留し、標準BOT/mainを変更しない。独立未使用シードも現段階では消費しない。

次は「砦を守る費用」「失うことで城が危険になる時間」「待った後に実際に出せるカードの戦力価値」「そのカードが砦を取り返せるか」を一つの判断として検討する。迎撃衛士固定で全部の砦を犠牲にするのではなく、**今守る / 見送る / 後退して城を守る / 再攻勢**という複数の行動選択が必要。

## 次のQA候補：防衛専用から奪還役へ（`fortTradeReclaim`）

従来の`concedeFort`では4エネルギー確保後に設置型迎撃衛士を出したが、その衛士自体は基地を奪い返せない。新変種では、現在の手札に重装工兵（4コスト）があり、**本来のユニット経路で喪失後の砦を目標にできる**ことを確認した場合だけ、衛士に代えて工兵に4エネルギーを貯める。それ以外は従来どおり衛士待ち。どちらも手札にない場合は通常防衛する。

11秒以内に資源が貯まったとき、砦を失っていて本当に工兵がそこへ向かうことを`getFort`で確かめてから正規の`spawn("engineer")`を実行する。砦がまだ味方所有、または経路に合わなくなった場合、迎撃衛士が払えれば衛士で守り、無理なら計画を破棄し通常防衛に戻す。**ユニット経路・相手情報・占領性能を改造しない。**

評価は2段階に分ける。計画→実際の喪失→工兵の合法出撃→出撃後の対象砦の再占領を別々に計測する。最初は旧候補との対照と通常BOTに対する既知シード比較とし、独立シードは試験の見込みを得るまで消費しない。無理に攻撃を継続するのではなく、城の緊急防衛と砲撃・対空等を優先する。正式採用は未定。
