# 小国戦線III｜既存BOTの低コスト先行防衛・試験 v1

研究専用 `forecastCheapScreen`（`develop` QA限定）。

## 仮説

前回の短期「スカウト用資源を貯める」候補は実際の試合で待機16回・次回スカウト投入8回となったが、通常BOTと30条件のカード使用・勝敗・基地保持の差が0。元のBOT自身が同じ局面で資源回復を待っていたことと整合的である。単なる再包装では実際の行動が変わらない。

そこで、防衛に関して**2エネルギーだけで実際に可能な動作を増やす**。

1. 味方が保持する前哨基地に、敵の地上部隊が6.5秒以内に到達しそうなとき（現実の `getFort` の目標＋公表速度による概算）。
2. 通常の緊急防衛・対空・範囲砲・結界の優先行動が必要ない。
3. 今の資源が2以上3未満で、魔導射手や迎撃衛士が購入不可。
4. 基地付近に防衛戦力が存在せず、敵が近すぎず、味方の召喚ラインから基地へ防衛部隊を送り込めるとき。

このときは、カード手札の中身に左右されず正規の常設基本歩兵（2コスト、2体）を先に召喚する。敵が近づいてから高いカードを買うより、早めの兵力配置が有効かを比較する。逆に資源の浪費で攻城力を失う可能性もある。

## 受入基準

`tests/online-bot-early-screen.cjs` が固定局面で「危険なら本当に歩兵2エネルギーを支払い、既に守られた基地・遠距離・空中敵・資源不足では使わない」を検証。

さらに既知学習シード17/41/73×青赤×self/rush/fortress/bankerの30対照条件＝通常BOT30・新候補30試合。平均城HP・基地確保時間・カード利用・勝敗・発動回数を測定。未使用holdoutは既知訓練成績が明確に良好な場合のみ投入する。通常BOT採用なし。

## 訓練実測と判定（[Actions #39049297258](https://github.com/8mahi8/shokoku-sensen/actions/runs/39049297258)）

固定局面では法定2エネルギーでの先行歩兵防衛、既存防衛の重複回避、遠距離・飛行・資源不足時の禁止が成功。一方、既知シード17/41/73・青赤・複数相手の実戦30条件は予測チェック370回に対して該当敵0件、投入変更0回、勝敗改善0・悪化0・差0、城HP・カード使用・基地保持差も0。実戦で動かないため正式BOTに採用しない。該当局面がまったくないか、既存の優先判断・急務判定が先に拾うかを分けて調べる。


## 実エンジンの到達時間を考慮した第2案

別途実施した[行動可能性観測](https://github.com/8mahi8/shokoku-sensen/actions/runs/39049517648)で、購入可能カードなし2,099/2,347判断、味方基地への敵到達見込み12秒以内の判断419、6.5秒以内256、そのうち緊急扱い前の短期接近31を確認した。初版の「敵到達6.5秒以内かつ基地から105px以内」という条件は、実際の出撃には狭すぎた。

そこで**味方の2コスト歩兵が実際にその基地まで移動する時間**を計算する。敵は12秒以内に基地へ到達する予測で、味方は通常配置地点から基地240px以内、移動時間が敵到達時間+1秒以内であること。実際の `getFort` の基地ターゲットと防衛配置の空きは依然維持する。前方に十分早く歩兵を置けるときだけ候補となる。採否は再試験後に判断する。


## 実移動時間ベースの初回比較（[Actions #39049719952](https://github.com/8mahi8/shokoku-sensen/actions/runs/39049719952)）

既知3シード・30条件の60試合で全テスト成功。予測チェック371、敵の接近候補14、**実際の先行歩兵投入7回**、カード使用構成変化3試合。勝敗改善0・悪化0。平均の自城残HP+14.5、敵城ダメージ0、基地保有時間+1.34秒、資源支出+0.23。青側では自城残HP-12、赤側+41、rush相手+102.5、防衛型相手-30と均一ではない。採用証拠としては不十分で、追加の既知シードによる再現性確認を行う。未知シードはまだ消費しない。

**結論：通常BOTには不採用。** 明確な勝敗優位がなく、特にRED側に防衛トレードオフが存在する。過去の6学習シードの結果から良い条件だけを後付け抽出しない。新しい独立シードを消費しない。QA専用コードは研究比較のため維持するが、通常の戦術・main・カード性能・回復速度には反映しない。

### 次の研究方針

無条件の待機・単発の防衛投入を追加するだけでは勝ち筋に届かない。次は資源・4枚の手札循環・前線喪失/維持・城HPの交換比率を含む**実際に選択可能なカードの短期価値**を測る。自軍と相手の既知資源回復、公開カード情報だけを使い、候補投入が城の守り/攻城にどの程度寄与したかを分ける。既存BOTの強さを壊さず局所QA比較で反証する。
