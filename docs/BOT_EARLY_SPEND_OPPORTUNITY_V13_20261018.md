## V12｜実際の支出による次の手札の購入遅延（観測のみ）

[Actions #39123141072](https://github.com/8mahi8/shokoku-sensen/actions/runs/39123141072) **SUCCESS**。
`tests/online-bot-early-spend-audit.cjs` は localhost HTTP の一時レスポンス内だけで既存の `online-game.js` の `decisionAudit` に事前手札、事前資源、事後実支出を記録。GitHub上の戦闘ソースは改造しない。
既知6seed×2陣営×4相手スタイル（selfは2地形）=**60対応条件／120フルゲーム**。通常BOTと観測方策の勝敗・城HP・カード・初期手札・キュー・支出・砦保持・資源整合性が全条件で一致。観測による行動介入なし。

開始から120秒以内に4,217件の専門BOT判断、実使用701回。カード使用：歩兵373、ライダー40、工兵42、魔導射手25、衛士42、ドローン50、制圧機兵46、砲撃35、結界48、大型戦車・ゴーレム0。うち既存手札の未購入ライダーに対する仮想的な購入可能時間を実支出によって延ばした判断 **56回**、工兵54回、迎撃衛士188回、戦車631回（複数の潜在遅延は同時にカウントし得る）。資源2以上3未満かつ手札に未購入ライダーが存在した状態での支出が56回。

**解釈の限界**：
- `secondsUntilAffordable()` による遅延は「この資源支出がなければ何秒で資源に届くか」の局所的理論値。次のカードが実際に使われた時刻の差ではない。
- 攻められている砦や城を守るための基本歩兵は価値がある。53%という歩兵使用割合だけで浪費と断定しない。
- ひとつの戦闘状況に近いBOT思考が繰り返される。4,217判断は独立4,217試合ではない。
- 各陣営・相手・勝敗での利用機会に偏りがある。

## V13｜守備兵がいる砦限定の3資源スカウト短期予約

観測だけでなく因果介入を検査するため、通常BOTと別名の `scoutTempoPreserve` を3つの配布エンジン（`online-game.js`／`online-embed.html`／`online-ipad.html`）へ **QA variant限定** で実装。通常の資源回復、手札、ユニット移動、城の緊急防御、範囲攻撃、対空・結界を優先する。

自城に迫る敵がいない／味方所有砦が襲われているが健在な守備戦力が近くにいる／未占領砦に新しい偵察ライダーが本当に向かうことを `getFort` で確認／ライダーが手札にあり最大4秒で3コスト到達可能／資源2以上3未満の場合だけ、2コストの追加歩兵を見送る。3資源まで届いたらライダーを正規召喚し、城の危険時は待たない。**過去の通常BOT・既存QA戦術を置換しない。**

[Actions #39123636819](https://github.com/8mahi8/shokoku-sensen/actions/runs/39123636819) **SUCCESS**（固定QAの挙動と120ペアを実行できたという意味で、勝率改善を意味しない）。

固定局面：敵が所有砦を攻め、近くの味方衛士が支援し得る場合、通常BOTは歩兵を出すが新候補は短期保存、3コストに到達すると正規の偵察ライダーを出す。敵が城に迫っている場合は新候補も歩兵迎撃に戻ることを検証。

訓練用6シード×2陣営×5相手スタイル×2設定（自己対戦は鏡像）=**120対応条件／240フルゲーム**、同一30Hz戦闘・資源・初期手札・キューでの比較。

| 指標 | QA新戦術 vs 通常BOT |
| --- | ---: |
| 勝敗改善／悪化／不変 | **0 / 1 / 119** |
| 自城HP平均差 | **-15.708** |
| 敵城へのダメージ平均差 | **-22.625** |
| 砦保持時間平均差 | +0.449秒 |
| 資源支出平均差 | 0 |
| カード使用内訳が異なる条件 | 3 |
| 短期予約したBOT判断 | **6** |
| 実戦中のライダー予約解除・投入 | **0** |

違いのあった3対戦は、青側（team2）に偏り、1条件で敗北が増えた。良い城HP差の条件が1つあっても、ほかの条件で大きな自城HP悪化があり、全体に一般化する根拠はない。

**採用判定：否決。** 貯蓄後に必要カードを合法的に購入できる静的な場面は存在するが、実試合では戦況が変化し、6回の予約が1回も実際の偵察ライダー投入に結びつかなかった。即時歩兵の防衛機会を犠牲にした可能性はあるものの、今回の対照実験のみで敗因の因果は断定しない。後から閾値を緩めたり特定seedだけ例外化したりしない。
