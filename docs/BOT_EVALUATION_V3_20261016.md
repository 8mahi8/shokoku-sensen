# BOT加速対戦・陣営差評価 v3（2026-10-16）

対象: develop 専用。main は変更しない。ゲームのカード・経済・勝利条件の数値は変更していない。

## 内容
- ローカルQAの \`runDuel(seed, scriptedStyle, difficulty, tacticalTeam, scriptedCadence)\` に第4引数を追加。戦術BOTを青（1）または赤（2）に配置できる。未指定は従来どおり赤（2）。
- 赤の通常BOTは従来どおり呼び出される。QAで戦術BOTを青に置いた場合のみ、通常の赤BOT実行を抑制し、赤を比較用スクリプトで操作する。
- 各軍の初期手札とデッキ順は同一。同じ乱数シードと相手戦術で左右の戦術BOT配置を入れ替える。
- 学習用シード 17, 41, 73 と未知評価用（holdout）2003, 2017, 2063 は混用しない。
- 3戦術（速攻 / バランス / 守備）× 3シード × 2陣営 × 2分割 × 2判断頻度（standard / fast） = **72試合**。同条件の再実行により決定性も確認。
- \`qa-bot-evaluation/matches.json\`：カード、基地、エネルギー、城HP、行動量など各試合の実測。\`pairs.json\`：陣営交換の対照ペア。\`summary.json\`：train/holdout の勝敗・陣営別統計。
- 比較スクリプトの思考間隔は fast で 0.65 倍。カード・資源は据え置き。判断回数増が本当に勝率を上げるかは結果から検証する。
- 損失時の高残エネルギー、基地劣勢、対空射手未使用を「疑いのシグナル」として記録。原因確定とは扱わない。

## 注意
これは同じ強さの戦術BOT同士による自己対戦ではない。基地位置と初期召喚Y座標も左右で厳密に対称ではなく、戦闘による乱数消費順も変わり得る。**同一シード・同一デッキ・同一相手判断頻度での入れ替え比較だが、厳密な完全ミラー実験ではない。** 勝率からカード性能を変えることも、対人の実力を推定することもしない。

## 実行
\`node tests/online-bot-evaluation.cjs\`。Playwright 1.56.1 とChromiumが必要。\`.github/workflows/online-bot-tactics.yml\` が既存18試合ベースラインと並行して実行し、結果をArtifactsに保存する。
