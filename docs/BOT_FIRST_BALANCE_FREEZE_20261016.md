# BOT優先・ゲームバランス凍結の開発方針

決定日：2026-10-16。ユーザーの指示に基づく小国戦線III開発の判断基準。

## 中核方針

**BOTが十分に強く、戦術に応じて合理的に戦えるようになるまでは、カード・ユニットのゲームバランスを安易に変更しない。**

現行版のユニットHP・攻撃力・射程・移動速度・コスト・数量・スペル効果、エネルギー回復・施設HP・勝利条件などの性能パラメータは原則据え置き。過去の対戦結果で大きな勝率差が出ても、まずBOT側の手札使用・ターゲット・配置・守備・前線管理の弱点を疑って反証する。

変更してよいもの：
- BOTの判断ロジック・探索、意思決定速度（難易度ごとの差は残す）
- 自動対戦環境・テレメトリ・再現性のあるテスト・分析
- 入力UI・描画・通信・重大なバグ修正（意図しないバランス変更を伴う場合はその影響を明示）
- BOTの思考を検証するためのローカルQA用シナリオや研究用の比較構成

原則変更しないもの：
- カード性能・召喚コスト・回数・エネルギー回復速度・勝利条件
- 試合本編でBOTだけが得をする隠れたHP/ダメージ/資源補正
- 一時的な勝率や少数試合の結果だけに基づく弱体化・強化

## 自動対戦の目的

**第一目的はBOTの弱点を見つけて修正すること。** このフェーズではゲームバランス変更を自動実行しない。

1. 同じルール・同じ資源で複数タイプのBOTと戦う。
2. 対戦ログ（勝敗、城HP、基地保有時間、召喚・スペル選択、未使用エネルギー、試合時間）を残す。
3. 負け方を、戦略不備・視界/索敵・手札使い残し・拠点防衛・対空不足などに分類。
4. BOT側の判断だけを変更し、別の固定シード・別の相手タイプでも改善するか検証。
5. 相手を変えても通用するか反証し、特定の相手にだけ勝てる過学習を避ける。

## ゲームバランスの検討を解禁する条件

BOTが複数の戦術に対して合理的に動作し、テストで十分に検証できる段階に達した後、**同じゲームパラメータの下で、複数の強い相手・初期条件でも明確な偏りが反復再現する場合**に限って検討する。実プレイヤーの体感・勝敗も照合。変更は小さく・一度に少なく・理由と実験結果を記録し、勝率を50%に近づけること自体を目的化しない。

## 現在の計測の限界

初回の自動対戦は**赤軍の戦術BOTと青軍の独立した簡易スクリプト3種類の比較**。これは同等の強さのBOT同士の完全な自己対戦でも、対人対戦でも、旧BOTとの厳密な性能比較でもない。結果はBOTの行動パターンを改善するための「基準値」であり、勝率をもってゲームバランスの是非を即断しない。

## リリース運用

公開 `main` は更新しない。研究・改修・テストは `develop` で続行。ユーザーに必要以上の承認を求めず、ただしゲームパラメータの変更はこの方針に従い保留する。
