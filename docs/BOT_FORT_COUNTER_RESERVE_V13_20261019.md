# 小国戦線III｜V13：砦応急防衛と4資源迎撃の機会費用・独立検証（2026-10-19）

## 結論

**通常BOT導入を棄却**。小さな新規ルールは、固定局面では期待通り「即時2資源の魔導射手を出さず4資源の迎撃衛士を待つ」を実行できた。しかし既知研究120ペアで勝敗改善1／悪化0だった後、**独立の未使用160ペア（320実ゲーム）で改善0／悪化0**。試合中の資源温存と城・砦の価値を正しく扱うには、局所的なルール追加でなく部隊の耐久・火力を観測して守る価値を算出する方向に研究を移す。

## 今回確認した外部研究

- [Stanescu, Barriga, Buro (2015), Using Lanchester Attrition Laws for Combat Prediction in StarCraft](https://doi.org/10.1609/aiide.v11i1.12780)：ダメージレースや戦闘の継続価値を考える際、HP/ユニット種類別の戦闘消耗を簡潔なモデルで見積もる設計に参考になる。論文のモデルは実データからユニット強さを学習し、安価な予測で攻撃・撤退判断に使う。**本作に対してこの論文の係数が有効と確認されたわけではない**。
- [Barriga, Stanescu, Buro (2017), Combining Strategic Learning with Tactical Search in Real-Time Strategy Games](https://doi.org/10.1609/aiide.v13i1.12922)：長期戦略と目の前の戦闘には異なる判断粒度が必要。局所行動と全体戦略を階層的に扱い、すべてを同じ重い予測で評価しない方針。
- 既存研究：[BOT_FORT_LAST_LINE_V1_20261018.md](BOT_FORT_LAST_LINE_V1_20261018.md)：目の前の砦喪失とその後の城ダメージは単純な近さだけで決定しない。以前の50秒局面テストでは「砦保持時間が長いが城被害も大きい」例を確認。
- 既存研究：[BOT_WORKER_REAL_DUEL_V12_20261019.md](BOT_WORKER_REAL_DUEL_V12_20261019.md)：Workerへ送れる候補は12完全試合の意思決定1,279回中、19回（1.49%）と稀。通常BOTの軽い判断そのものを良くすることを優先。

## V13 研究限定の政策

`tests/online-bot-fort-counter-reserve-v13.inc.js`。localhost QAサーバが既存の `botExpertAction` 内の砦緊急処理前にだけ一時挿入、`runDuel` の許可リストもlocalhostの配信内容でのみ拡張。`online-game.js` のGitHubソース、通常BOT、公開main、オンライン対戦のコードは**一切変更していない**。

比較条件は次の通り。自軍の占領砦が敵に襲われ、敵部隊1–2・近くに戦闘可能な味方防衛兵なし、当該4資源迎撃衛士が実際に今の自分の手札にある、現在エネルギー2～4、必要な自然回復は4.8ゲーム秒以内。城壁への敵接近がない、敵の足が速すぎない等の可視状態の保護条件を通ったとき、**そのBOT思考1回では2コスト応急兵を買わず待機**。次の通常思考時に再評価し、4資源が貯まれば元の4資源迎撃処理が働く。相手の非公開の手札・本当の資源残額・未来の行動は使用せず、ゲームの召喚・耐久・物理ルールも変更しない。

これは「砦を必ず捨てる」方針ではなく、4資源級の迎撃力と目先の2資源投入の**機会費用**を一度だけ比較する実験案。既知シードの勝利を見て条件を後付け修正しない。

## 判定と次段階

- **V13を通常BOTに導入しない**。研究用script/CI/報告だけを保持。パラメータを独立結果に合わせて調整して「独立評価を通った」と装わない。
- 過去の砦放棄・ドローン資源予約も本番勝率の改善が乏しい。次は**敵味方の見える部隊の火力・HP・対空能力・持続時間から、砦を守った場合／放棄した場合の戦闘損失の見込み**を速く算出し、事前予測と同一ゲームエンジンの事後実被害を照合する。単一の距離や固定エネルギーしきい値ではなく、根拠になる戦闘価値を持たせる。
- 研究開始時に予測対象・正解ラベル・時刻・評価指標を凍結し、研究seedと新しい独立seedを混ぜない。意思決定への採用はその後の勝率A/Bで判断する。
- **学校iPad Safari・Google Sites・Firebaseオンラインは変更しない**。実機検証・本番反映は別途受け入れ基準を満たしてから。
