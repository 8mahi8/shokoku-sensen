# 小国戦線III｜砦を明け渡した後の15秒・30秒と敵増援を観測

2026-10-18。前のQA版では`fortTradeReclaim`（4コスト重装工兵優先）と`fortDefenseValue`（高速敵には4コスト迎撃衛士優先）の勝敗は同じで、後者は既知120比較ペアで自城HP平均+14.875、しかし工兵による対象砦の再確保3→0だった。全長試合の最終勝敗だけでは、反撃した後の15〜30秒の交換損益や敵の増援への耐性を判断しづらい。

今回は戦術を増やすのでなく**実際の30Hz戦闘エンジンでの観測**を追加。砦一時放棄の計画開始ごとに、時刻・砦・選んだカード・開始時の城HP/敵城HP・所有砦数・可視敵数を記録し、15秒後と30秒後に以下を測る。

- 自城と敵城の累積被ダメージ
- 対象砦を保持できた合計秒数・15/30秒時点での所有者
- 実際に砦を失った時刻、再確保した時刻
- 当該期間中に敵が合法的に追加召喚したカードの回数と総資源コスト

敵の召喚は既存の試合BOT/スクリプトが本来のルールで実行するものだけを数える。新しい偽ユニットや資源の不正補充は行わない。一定時間より前に勝敗が確定する局面は、短い観測窓の指標に混ぜない。対戦は既知6シード×青赤×5相手×標準/高速または自己対戦鏡像の120セットを、通常BOT/工兵型/衛士優先型の3種類で実施（計360全長試合）。当該試合で発動した計画を層別し、城の損失と砦の所有・敵の追加召喚を整理する。

**重要な制限：** 各計画はBOT自身の状態から選ばれたものであり、同じ局面における無作為化された「工兵対衛士」比較ではない。15/30秒の測定は説明的観測に限定する。勝敗/残城HPは同一シード条件の対照として提示する。既知シードでの良好結果を採用条件にしない。公開mainと通常BOTは不変。

## 初回15秒・30秒の実測（既知シードの比較）

[GitHub Actions #39063806429](https://github.com/8mahi8/shokoku-sensen/actions/runs/39063806429) は360試合で成功した。工兵優先22件・迎撃衛士優先22件、合計44件の一時砦放棄計画が観測された。ほとんどは**同じ局面に対する２候補の対応する観測**で、44独立例と解釈してはいけない。

- 作戦開始から15秒での平均自城被ダメージ0、30秒で約336.95。
- 44/44計画で開始後30秒以内に敵が合法的に追加召喚。平均3.5回、資源コスト約8.59。
- 30秒間で38/44計画の対象砦が失われ、0/44計画で30秒以内の再確保が成立。
- 両候補の30秒間平均自城ダメージは同じで、全長試合120対照条件の勝敗差もゼロ。全長自城HPでは迎撃衛士優先型が平均+14.875で、明確な勝敗改善はない。

この30秒は工程の早い側面に偏るため、さらに60/90秒の自城・敵城ダメージ、砦再奪還、移動した召喚境界、敵の追加召喚回数を追跡する。試合が早期終了し観測できないものは欠測として数え、平均比較から除外する。通常BOT・公開main・資源やユニット性能は変えない。
