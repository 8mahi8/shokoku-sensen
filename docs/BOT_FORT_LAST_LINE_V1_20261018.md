# 小国戦線III｜城への最後の防衛線を考慮した砦放棄 (QA限定)

2026-10-18。前回の`fortRiskBudget`は固定局面では放棄を拒否できたが、既知120ペアで拒否0、通常の奪還型と勝敗・自城HPとも差0だった。既存の`fortTradeReclaim`は4回の工兵出撃で3回砦が戻ったものの、`concedeFort`より平均城HPが-19.5。城を守る目的と砦を取り返す目的が衝突し得る。

別のQA計測では、**砦喪失時点で城までの可視敵の直線ETAが10秒以下**の区間で、30秒観測できた56件中54件に城ダメージが確認された。ただし喪失を原因と断定できず、失う前から城が攻撃されているケースが含まれ得る。これを**予測モデルの正しさとは扱わない**。

新候補`fortLastLine`は、`fortRiskBudget`の法定4コスト待ちを基本とし、次をさらに考慮する。

- 占領中の味方砦が1個だけなら、可視敵の城接近最速ETAが24秒以内、かつ城付近に味方の防御部隊がいなければ放棄せず従来の緊急防衛へ戻す。
- 味方砦が2個以上なら、上記ETAが16秒以内・城付近を守る味方がいないときは、砦を守る方へ切り替える。前方砦が十分離れているなら資源を貯める選択肢は残す。
- 自城HPが半減している局面では追加リスクを許容しない。
- 途中で敵が接近し、城への危険が増したら資源温存を打ち切る。4枚手札・移動ルール・公開資源・ユニット性能は変更しない。
- 占領の経路が有効な場合のみ重装工兵を奪還役に選ぶ。不適合なら迎撃衛士など元の防衛へ戻す。

24/16秒という閾値は、過去の**既知訓練シードからの試行的な保守設定**であり保証はない。既知の6シード×青赤×5スタイル×2条件で、通常BOT・直前の`fortRiskBudget`・新`fortLastLine`を各120回（合計360試合）対照比較する。固定局面では「城に近い最後の砦では守る」「別の砦が味方にあり前方で余裕があるなら待機・4コスト工兵で奪還」を要求する。改善が弱ければ通常BOTへの導入と独立シード消費を見送る。
