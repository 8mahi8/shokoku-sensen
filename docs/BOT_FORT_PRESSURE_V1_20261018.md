# 小国戦線III｜奪還か攻勢か：判断開始時点の見える情報を検証

2026-10-18。develop QA専用。公開main・通常BOT・ユニット性能は不変更。

## 問いと問題
前回は各政策22エピソード中14エピソードで、砦の再確保より先に自軍が勝った。ただしこれは**事後ラベル**であり、開始時点で攻勢重視が最善だった証拠ではない。事後の勝者をBOTに使わせず、計画開始時点の信号を独立に記録する。

## 記録する観測信号
城HP差（自城－敵城）、味方と敵の現存ユニット数、敵城壁面から水平300px以内の非guard味方数、自城壁面から300px以内の敵ユニット数、各城壁面までの両軍ユニット最短水平距離。いずれもBOTが実際に観測可能なゲーム内公開情報であり、将来の増援・後の勝敗は含まない。300pxは分類のための暫定測定幅で、政策のしきい値ではない。

## 評価
既存の30Hzフルゲーム 6既知シード×2陣営×10対戦条件＝120条件、通常・工兵優先・衛士優先の360試合を再実行。QA `tests/online-bot-fort-horizon.cjs` が `qa-bot-trade-horizon/pressure-audit.json` を出力する。計画開始時に凍結した特徴と、90秒以内の先着イベント（奪還/終局）を事後照合する。対応する両候補の同一局面を別々の独立標本とは数えない。

分析コードでは、「砦を最初に失ったのが90秒より後」を90秒までの未奪還に誤分類しない境界テストも追加。対象砦が最後まで失われない場合は再確保不要。

**採用はしない**：本変更は観測だけで、勝敗改善・最適判断はまだ実証していない。次の戦術実験は、事前に評価式と比較基準を決め、既知シードで調整しすぎず、holdoutは最終確認時まで保存する。
