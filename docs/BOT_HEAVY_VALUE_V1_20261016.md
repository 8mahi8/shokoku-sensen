# 小国戦線III｜大型ユニットの費用対効果研究 v1

目的：7コストの守護ゴーレム／魔導重戦車が「BOTが使わないから弱く見える」のか「役割に対して単純に不利なのか」を分離する。

## 評価設計（ゲームパラメータ完全凍結）
- 実ゲームエンジンの\`playCard\`と\`tick(1/30)\`を使用。両側の初期HP・カード性能・コスト・エネルギー回復は変更しない。
- 攻城：魔導重戦車（7）対、制圧機兵（5）＋魔導射手（2）。空城、軽い警備、重い防衛、敵大型の4条件。
- 防衛：守護ゴーレム（7）対、迎撃衛士（4）＋偵察ライダー（3）。敵歩兵群、敵大型、飛行、遠距離の4条件。
- 同じ条件で青軍・赤軍を交代、初期乱数6種類、2編成を比較。**96組×2編成＝192局面**。一局面はゲーム内120秒まで。
- 両陣営は正式な配置可能範囲内で実際のカードを支払い、実際の攻撃・索敵・移動で戦う。後続のBOT召喚は止めて初期7コストの純粋な戦闘寄与を計測。
- 記録：敵城へのダメージ、敵ユニットへの実ダメージ、自城被害、部隊生存秒数、撃破数、初交戦時刻、基地所有状態。
- 攻城側は前進した前哨基地から、防衛側は自城付近で開戦する。条件を固定した**特定局面の比較**であり、実際の対人勝率やカード全体の期待値を示さない。
- 乱数消費は部隊数で変わるため、同じseedでも完全な共通乱数ではない。連戦の学習／未知評価セットとは別の**診断用**seedとして扱う。

判定方法：重戦車は敵城へのダメージや警備突破を、ゴーレムは敵部隊への与ダメージや自城防護を中心に評価。「大型を増やす」こと自体を目標にしない。性能調整は実際の用途とBOT判断を双方理解するまで引き続き凍結。


## 追加検証：勝敗までの早さと途中経過

初回120秒の結果では、攻城側で両編成が敵城HP3000を削り切ったため、**最終ダメージは天井に張り付き比較不能**。この問題を防ぐため30秒・60秒・90秒の時点の攻城/被害スナップショットと城破壊時刻を計測する。打ち切り時点で未破壊の場合、城破壊時間の集計は121秒（120秒超）とみなす。あくまで有限観測窓の代理尺度。

初回の守護ゴーレムは対敵大型・遠距離で自城被害を大幅に減らした。ただし偵察ライダー等との比較であって、対空防衛を単独で担えるわけではない。防衛ゴーレムは兵種相性で価値が変わる。

青赤両軍・同コストのパターン比較だけでは、実際の手札回し、7コスト到達までの機会費用、複数波の戦闘・対人戦への一般化は確定できない。
