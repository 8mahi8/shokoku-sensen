# 小国戦線III｜2コスト歩兵の防衛実効性・局面対照QA

2026-10-18。ユーザーの「あえて耐える」戦術検証の次段階。前回の砦喪失/城到達ETAだけでは防衛投入2コストが実際に敵を止めるかは判定不能だった。

localhost限定の`simulateDefenseOpening`を追加。現在の通常BOTの判断を変えずに、**初動だけ**次の4案を合法な同条件シーンから比較する。

- baseline：通常BOTの実際の初動選択。
- infantryNow：2エネルギーを支払い、常設2体歩兵を即時召喚する。
- skipFirst：最初の1.5秒のBOT判断を見送り、次の判断以降は通常BOT。
- saveFor4：資源が自然回復して4に達するまで何もせず、手札に存在する重装工兵または迎撃衛士（4コスト）を正規召喚した後、通常BOT判断へ戻る。

基準値の城HP・砦所有時間・初期敵兵生存・城域侵入・初回召喚時刻・消費資源・歩兵が与えた実ダメージ/攻撃回数を計測する。実ゲーム30Hzの移動・攻撃・資源回復を使用し、ユニット性能や召喚ルールは改変しない。既知5シード×7定義済み局面×4案、計140シミュレーション（35対照セット）、各50秒を計測。敵の追加召喚はなし。**全対戦の強さや独立holdoutではない**。

仮説：大きな敵に近距離で基本歩兵2体を出すと、短時間で消耗して砦を守れず、4コストの耐久のある迎撃や工兵の方が城被害が小さくなる場合がある。ただし高速斥候/城直近では即時歩兵の足止めが有効かもしれない。両方をテストし、どちらでもいい条件を見つけたら勝敗改善と混同しない。

**採用基準**：固定局面で分岐の効果が説明でき、既知シードで平均的な自城被害・敵の突破・資源機会費用に大幅な副作用が出ないこと。実際の対戦BOTへの採用は、後の独立シードと人間のプレイで検証してから。開発先はdevelopだけで、公開main・通常BOTは不変。
