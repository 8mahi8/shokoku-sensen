# 小国戦線III｜偵察ライダー投入レーンの拡張訓練比較

前の狭い改善候補3つ（既存BOT比較各30条件）のうち laneScout は勝敗改善1、悪化0、変更されたカード内訳2試合、行動発動4回とわずかに有望。他の preemptFort と escortCapturer は勝敗差0だった。

ここでは新しい未使用のholdoutは使わず、以前の研究で使用済みの train シード17/41/73/101/131/163を使用する。青赤×自己対戦地形2種、さらに rush/balanced/fortress/banker の相手行動間隔 standard/fast を組み合わせ、合計120対照条件＝基準120試合＋候補120試合で検証する。

判断は実際の getFort の移動先を考慮する「偵察ライダー投入レーンの選択」のみ。それ以外のBOT、移動AI、カードの性能・コスト、手札・資源は変更しない。勝敗の増減、実際に変更した判断回数、カード使用内訳、城HP・与ダメージ・基地保持秒数と、陣営および相手戦術別の差を比較する。

採用判断：まだ訓練段階。既知シードで再現性と両陣営への影響が確認でき、トレードオフが許容できた候補だけを新規の未使用シードで独立評価する。

## 拡張訓練結果（[GitHub Actions #38894108837](https://github.com/8mahi8/shokoku-sensen/actions/runs/38894108837)）

240試合（同条件120対照＋120候補）を実施。回帰・再現・資源照合テストを含め全CI成功。

| 指標 | laneScout vs 通常BOT |
| --- | ---: |
| 比較条件 | 120 |
| 勝敗改善 | 1 |
| 悪化 | 1 |
| 変化なし | 118 |
| 純勝敗差 | **0** |
| レーン選択を変えた判断回数 | 22 |
| カード内訳が変わった対戦条件 | 14 |
| 敵城へのダメージ平均差 | +17.98 |
| 自城の残HP平均差 | -2.77 |
| 基地確保時間の平均差 | +4.49秒 |

**相手スタイル別**：自己対戦0/24、rush 0/24、balanced 0/24、fortress +1/24、banker -1/24。**陣営別**：青60条件で改善1・悪化1、赤60条件で改善も悪化も0。**行動間隔別**：標準72条件では差+1、高速48条件では差-1。

この結果は『守備相手なら有効、資源を貯める相手には不利』という仮説を生むが、各結果はわずか1試合ずつであり確立された優劣ではない。独立未使用シードを使う前段階でも安定した利点が得られていない。**正式BOTに昇格しない。** ここでレーン用閾値を繰り返し最適化すると既知シードへの過学習になるため、この方向の条件調整は停止。

## 研究方針

静的なカード優先順位や場当たり的な閾値の追加では、これまでの複数アブレーションでも勝率改善が継続しなかった。既存BOTは雑なようでも深い基地へ直接向かう戦術的な強みを持っている。次に進むなら、単純な占領レーンの変更でなく、**部隊の実際の数秒後の位置・拠点に与える占領ダメージ・迎撃時間・資源の機会費用を一体として評価する短期戦術予測**が適切。これは今後の新仮説であり、実証された改善ではない。

公開main、通常BOTの意思決定とユニット移動、カードバランスはすべて維持。
