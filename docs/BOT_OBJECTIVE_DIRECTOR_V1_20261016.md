# 小国戦線III｜戦略ディレクター実験 v1（QA専用）

従来の対空・緊急防衛・範囲砲撃などの処理は維持しつつ、平時のカード選択について未確保の前哨基地を横断的に比較し、既存の占領部隊の配置・敵の守備・自軍支援と距離から攻略先を選ぶ。

## 新戦略の判断順序

1. 自軍の占領済み基地が実際に危険なら迎撃衛士または魔導射手で保持する。
2. 未占領基地を全て評価し、距離・敵守備・味方占領部隊の不足から優先順位を付ける。固定の最寄り基地を必ず攻撃するとは限らない。
3. 占領役が不在なら送り込む。守備がある場合は重装工兵を優先する。
4. 占領役が進軍中に守備隊と衝突するなら、占領役を増やすより制圧機兵・魔導射手で支援する。
5. 前線が整ったらドローン、支援砲、大型攻城を検討する。非常時以外に小型歩兵をやみくもに増やすことを避ける。無条件の重戦車貯蓄もしない。

これらは objectiveDirector と名付けた localhost QA専用候補。既存BOTの一般プレイ、オンラインの対人挙動、カード性能は一切変更しない。

## 比較設計

シード17/41/73/101/131（過去使用した学習シード）、青赤、自己対戦通常と地形反転、rush・fortress・banker戦術という50条件で、基準と候補合計100試合を自動対戦。勝敗だけでなく城ダメージ・自城の残HP・基地占拠時間・資源投資・実際のカード使用と各戦略判断を収集する。

学習シードの結果が有望なら、その後は未使用シードで完全独立評価する。改善が出ない場合や片側だけでしか効果が出ない場合は、そのまま正式BOTへ取り込まない。
