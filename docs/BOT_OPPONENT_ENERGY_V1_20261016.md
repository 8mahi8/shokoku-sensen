# 小国戦線III｜敵資源観測と戦術意思決定 v1（develop専用）

## 公平性と実装
相手の\`S.energy\`や非公開の手札を直接見るのではなく、各陣営とも既知の初期資源8、公開されるカードの使用コスト、共通の資源回復時間を用いて観測可能な資源値を復元する。\`S.observedEnergy\`を独立更新し、実値\`S.energy\`とは意図的に切り離す。対戦中の資源回復上限は従来12。ゲームバランス・資源回復・カード能力・行動決定間隔は不変。

1. 正規\`playCard\`成功時にそのカードの公表コストを控除。不成立、単なるネットワークコマンド送信では控除しない。
2. \`tick\`で既存ゲームと同一の回復速度を積算。
3. QAで観測値と実値を照合し、実際の相手エネルギーだけを改変しても観測に基づくBOT判断が変わらないことを確認。
4. 相手の手札が非公開なので、大型・範囲砲撃を実際に持っているとは想定しない。

## 学習用A/B仮説
- \`opponentPunish\`：敵推定資源2.5以下なら、味方前線が現存し、実際に攻略すべき基地があり、緊急防衛不要な場合のみ偵察を追加して前線の勢いを維持。
- \`opponentGuard\`：敵推定資源7以上なら、敵が実際に前線へ来ていて、味方陣形があり、該当レーンの迎撃衛士がいない場合のみ先回りして防衛。
- 両方、通常BOTから分離された**QA専用方策**。標準BOTはまだ変更しない。
- シード17/41/73/101/131/163、基地通常/反転、思考順序青赤、候補陣営青赤で96比較試合+24基準試合。学習用データのみ。新しい未知シードは評価候補が固まるまで使用しない。

狙いは大型召喚を無理に増やすことではない。「敵が今どのくらい対応できるか」を部隊数・前線維持・基地への圧力と合わせて評価し、同じコストでも投下するタイミングを変えること。
