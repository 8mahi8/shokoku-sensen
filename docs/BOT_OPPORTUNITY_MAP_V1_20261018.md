# 小国戦線III｜行動可能性の実測マップ v1

3つの直近QA案は固定局面テストでは動いたが、学習用の対戦では通常BOTのカード使用や結果に差が出なかった。

そこで通常のBOTを変更せず、QA観測variant `opportunityAudit` で「手札の何枚が購入可能か」「ライダーが手札かキューか」「基地確保に必要な局面か」「敵が味方基地に6.5秒・12秒以内に到達できるか」「緊急防衛で先に処理されているか」を各行動の直前に計測する。

本実験は戦術の採用判定ではなく**次の仮説を絞るための観測**。同一条件の基準と観測試合を対で回し、勝敗・経過時間・手札初期化・城HP・攻撃ダメージ・使用カード・実支出・基地保持時間・最終エネルギーまで一致することを機械的に検査する。敵の真の資源・非公開手札は参照しない。既知シード17/41/73、30組60試合を使い、未知シードを消費しない。

実際のゲームに見られなかった局面を架空の課題として永遠にチューニングせず、出現する問題を測ってから候補を作る。公開mainは変更しない。


## 実測と重要な解釈

[Actions #39049517648](https://github.com/8mahi8/shokoku-sensen/actions/runs/39049517648) 成功。30組60試合、通常BOTと観測variantの戦闘結果・手札初期化・全カード使用・HP・資源・基地保持が完全一致（観測の副作用なし）。計2,347回の判断を取得。

| 観測条件 | 回数 / 全2,347判断 |
| --- | ---: |
| 手札4枚のうちその時点で買えるカードなし | 2,099 / 89.4% |
| 資源2未満 | 1,330 / 56.7% |
| 資源2以上3未満 | 609 / 25.9% |
| 偵察ライダーが手札 | 290 / 12.4% |
| 偵察ライダーが待機列（キュー） | 2,057 / 87.6% |
| 味方基地に敵が12秒以内に到達見込み | 419 / 17.9% |
| 味方基地に敵が6.5秒以内に到達見込み | 256 / 10.9% |
| 緊急判断が先に必要 | 1,058 / 45.1% |

「購入可能な手札なし」は無制限の基本歩兵まで含むわけではない。資源2以上なら基本歩兵を合法的に出せる（手札のカードと別）。そのため「89.4%は何もできない」という解釈は**誤り**。また「偵察ライダーが待機列」は通常の循環に含まれることであり、そのものがバグの証拠ではない。

前回の予測介入が発動しなかった原因は、局面の少なさと手札・資源・既存防衛優先の多重制約にある。今後は固定局面だけでなく、毎試合の行動可能性ヒストグラムを根拠に候補を作る。観測の成功を勝率向上と混同しない。
