# 小国戦線III｜行動可能性の実測マップ v1

3つの直近QA案は固定局面テストでは動いたが、学習用の対戦では通常BOTのカード使用や結果に差が出なかった。

そこで通常のBOTを変更せず、QA観測variant `opportunityAudit` で「手札の何枚が購入可能か」「ライダーが手札かキューか」「基地確保に必要な局面か」「敵が味方基地に6.5秒・12秒以内に到達できるか」「緊急防衛で先に処理されているか」を各行動の直前に計測する。

本実験は戦術の採用判定ではなく**次の仮説を絞るための観測**。同一条件の基準と観測試合を対で回し、勝敗・経過時間・手札初期化・城HP・攻撃ダメージ・使用カード・実支出・基地保持時間・最終エネルギーまで一致することを機械的に検査する。敵の真の資源・非公開手札は参照しない。既知シード17/41/73、30組60試合を使い、未知シードを消費しない。

実際のゲームに見られなかった局面を架空の課題として永遠にチューニングせず、出現する問題を測ってから候補を作る。公開mainは変更しない。
