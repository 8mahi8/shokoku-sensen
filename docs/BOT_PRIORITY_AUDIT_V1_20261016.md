# 小国戦線III｜BOT行動優先順位の観測 v1

「敵が何秒で資源を回復するか」だけの条件を変えても実戦では行動が変わらず、48比較ずつで勝敗差0だった。これ以上の閾値の緩和ではなく、**その瞬間に実際どのカードを選んでいるか**を可視化する。

## 検証設計

- \`botExpertAction\`にQA限定の \`try/finally\` 監査を追加。BOTの決定ロジックを変更せず、どのreturnでも記録する。
- 各判断直前の手元資源、観測敵資源、敵4コスト回復までの予測時間、自軍前線、所有基地、敵接近、重戦車が手札にあるかを記録。
- 結果を防衛・基地進行・前進準備・攻城の4状況と資源4段階で分類し、実際に使用したカード別回数、何もしない回数を集計。
- 重戦車を手札に持っているのに7コスト未満で使えなかった回数、前線が揃っていても低コストを先に出した回数、7コスト確保済みの好機回数を分ける。
- 自己対戦・攻撃型・バランス型・banker型相手、青赤交替、学習用の3シード。観測対象は24局面以上で、試験はCIで正確に試合数を固定。
- 元々行われる冒頭の配置は専門BOTの決断から除外。試合毎の初回40件の重要判断をサンプルとして残し、残りは全件計数。
- サイドごとに「監査された非冒頭行動数＝実プレイされた非冒頭行動数」を検査し、行動を取り逃していないことを担保。

**重要**：これは因果実験ではない。候補を変えて勝率が上がったと主張せず、次に試すべき判断構造を検出するための検査。カードバランス・公開main・通常BOTの戦術は一切変更しない。
