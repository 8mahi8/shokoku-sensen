# 小国戦線III｜防衛スクリーンを考慮した攻城投資試験

以前の資源貯蓄試験は、計画を6回立て、全6回とも敵が自軍の召喚境界に近づいたため途中で中断した。一方、敵が単に近いだけでは、その敵を味方が迎撃できているか判別できなかった。

今回は正式な対戦AIやカード能力には変更を加えず、\`screenBudget\`という **localhost QA専用候補** を作り、以前の\`stagedBudget\`と比較する。

- 占領済み基地・健康な占領部隊2体以上・手札の重戦車・緊急防衛なし、という従来の条件を維持する。
- 自軍の召喚線160px以内へ来た敵でも、同レーン近距離に健康な味方がおり、敵が飛行しているなら味方に対空能力があれば「一時的にスクリーンされている」と判断する。**敵がいるだけで攻城投資を止めない**。
- 一体でもスクリーンされていない接近敵がいる、基地や前線を失った、緊急の城・基地防衛が必要なら直ちに投資計画を中断する。
- 投資計画は最大23秒、取り消し後18秒の冷却、戦車出撃後14秒の冷却というルールを維持。危険な無条件貯蓄には戻さない。
- 固定局面で「護衛されている地上敵なら待機する」「護衛されない地上敵なら守備へ戻る」「対空能力のない味方は飛行敵を護衛済みと数えない」を検査。
- trainシード17/41/73、青赤、同一開幕手札と同乱数、自己対戦（地形反転含む）・rush・fortress・banker の30局面で、baseline/stagedBudget/screenBudget 3条件計90試合。
- 観測した取り消し理由と、その時の近接敵数・護衛対象数・敵の接近距離・自軍資源を局面ごとに保存する。

**判定**：単なる重戦車使用回数でなく、勝敗、基地占領、城への被害、どの局面で安全に投資できたかを合わせて評価する。学習用シードなので、有望でも採用前に未使用シードを固定した検証が必要。

今回の実験には「近い味方が実際にどれくらい敵の進軍を遅らせるか」という戦闘実測までは含まれていない。敵の距離だけでなく、その敵に対して防衛力が十分かも別の局面試験で反証する必要がある。
