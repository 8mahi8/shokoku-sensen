# 小国戦線III｜防衛スクリーンを考慮した攻城投資試験

以前の資源貯蓄試験は、計画を6回立て、全6回とも敵が自軍の召喚境界に近づいたため途中で中断した。一方、敵が単に近いだけでは、その敵を味方が迎撃できているか判別できなかった。

今回は正式な対戦AIやカード能力には変更を加えず、\`screenBudget\`という **localhost QA専用候補** を作り、以前の\`stagedBudget\`と比較する。

- 占領済み基地・健康な占領部隊2体以上・手札の重戦車・緊急防衛なし、という従来の条件を維持する。
- 自軍の召喚線160px以内へ来た敵でも、同レーン近距離に健康な味方がおり、敵が飛行しているなら味方に対空能力があれば「一時的にスクリーンされている」と判断する。**敵がいるだけで攻城投資を止めない**。
- 一体でもスクリーンされていない接近敵がいる、基地や前線を失った、緊急の城・基地防衛が必要なら直ちに投資計画を中断する。
- 投資計画は最大23秒、取り消し後18秒の冷却、戦車出撃後14秒の冷却というルールを維持。危険な無条件貯蓄には戻さない。
- 固定局面で「護衛されている地上敵なら待機する」「護衛されない地上敵なら守備へ戻る」「対空能力のない味方は飛行敵を護衛済みと数えない」を検査。
- trainシード17/41/73、青赤、同一開幕手札と同乱数、自己対戦（地形反転含む）・rush・fortress・banker の30局面で、baseline/stagedBudget/screenBudget 3条件計90試合。
- 観測した取り消し理由と、その時の近接敵数・護衛対象数・敵の接近距離・自軍資源を局面ごとに保存する。

**判定**：単なる重戦車使用回数でなく、勝敗、基地占領、城への被害、どの局面で安全に投資できたかを合わせて評価する。学習用シードなので、有望でも採用前に未使用シードを固定した検証が必要。

今回の実験には「近い味方が実際にどれくらい敵の進軍を遅らせるか」という戦闘実測までは含まれていない。敵の距離だけでなく、その敵に対して防衛力が十分かも別の局面試験で反証する必要がある。


## 実測：全90試合（2026-10-16）

[GitHub Actions #38887864367](https://github.com/8mahi8/shokoku-sensen/actions/runs/38887864367) が **SUCCESS**。固定戦況の「防衛部隊が近くにいて護衛できる」「護衛がない」「護衛は近いが対空できない」をすべて検査し、同じ訓練条件30組×baseline／旧投資案／新スクリーン案の合計90試合を完了。

新案の判断時点では「同じレーンで護衛可能と判定した敵」を延べ1,026件、「護衛できない敵」を延べ4,739件観測した。**これらはBOTが判断するたびに再度数えた敵接触の延べ回数**であり、実際の敵ユニットの個体数や試合数ではない。

新案の計画終了8件の理由は、迎撃できない敵の接近6件、健康な前線占領部隊が2体未満になった2件。固定シナリオでは両者を適切に区別できても、実戦では前線防護が戦車出撃に必要な長さまで継続していない。

### 判断

- **勝率への効果は認められず、正式BOTへ不採用。** 旧案と新案で勝敗結果が同じ1改善・0悪化でも、先行研究を含め学習済みシードであり一般化を示さない。
- 「近い敵すべてを危険とする」のは過度に保守的だったが、「味方が近くにいれば安全」という判定に変えるだけでも不十分だった。
- 将来の計測では、敵の進軍速度・攻撃射程・自軍スクリーン部隊の残HP・索敵方向から**何秒持ちこたえられるか**を推定し、その期間を大型までの必要資源回復時間と比較する。
- 特に敵が複数レーンに分かれると、1体を防いでいても他の1体が進軍できる。**レーン全体の防護率・スクリーンの配置場所・敵の突破予測**を評価する必要がある。
- ただし大型を出すことだけを目標にせず、7コストまで貯めることで失う即応戦力と基地占有時間も比較する。大型単体の攻城効果は既に確認したが、資源機会費用込みの対戦優位はまだ実証できていない。

## 検証上の注意

最初の回帰は **FAILURE** だったが、これは「護衛がない場合は必ず偵察ライダーを出す」という過剰に限定されたテストの期待値が原因。既存BOTは当該局面で魔導射手を選択していたため、「実際に資源を支払う有効な防衛・展開行動へ戻った」を確認するテストへ修正して再実行した。修正後はBOT戦術/新規比較とも成功。

新案は \`qaBotVariants\` による**開発用試験限定**。通常BOTの判断、ゲーム内数値、オンライン対戦、公開mainは変更していない。なお「敵を護衛できる」かどうかの簡易条件は実戦中の生存保証を意味しない。
