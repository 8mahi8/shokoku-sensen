# 小国戦線III｜BOT自己対戦 v1（develop限定）

- 戦術BOTを**青と赤の両側に同時配置**するQA専用モードを追加。公開ゲームの戦術は変更せず、ゲーム本体のカード性能、エネルギー、勝利条件は凍結を維持。
- \`runDuel(seed, "self", difficulty, firstActionTeam, "standard", mirrorTerrain)\` で実際の戦闘エンジンを30Hzで300秒まで加速実行。
- 以前のシード分割を維持：train=[17,41,73]、holdout=[2003,2017,2063]。
- 2難易度（hard/normal）× 6シード × 2地形（通常/基地X左右反転）× 2判断順序（青先/赤先）= **48試合**。
- 両軍同じ初期デッキ、同じBOTロジック、同じ思考間隔、同じ資源。出すカードはゲームの正式な配置・支払関数を使う。
- \`qa-bot-selfplay/matches.json\` \`pairs.json\` \`summary.json\` に陣営別勝敗、戦闘時間、基地保持、エネルギー、城HP、行動量、カード使用内訳を保存。
- 同一シード・同一条件で同一試合結果となることを再実行で検証。
- 通常側BOTがQAで赤以外に置かれる際、手札確認が赤固定だった大型召喚処理を修正（通常ゲームは赤を使うため挙動は従来のまま）。

## 判断上の注意

- これは比較スクリプト相手ではない、**同一戦術BOT同士の自己対戦**である。
- 左右地形反転は基地のX座標の反転に限る。地形・UI全体の物理ミラーを保証しない。初動やPRNG消費は左右交換で同一にならない可能性がある。
- 比較結果は左右差や序盤判断の弱点探索のためのもの。僅かな勝率差で性能値を変更しない。
- holdoutで発見した特定シードを改善施策に利用する場合は、汚染済みとしてtrainへ移し、新しい未知シードで再評価する。
- 旧BOTと新BOTの強さ比較や、実機対人の勝率は今回の評価範囲外。
