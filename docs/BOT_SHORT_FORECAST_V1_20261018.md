# 小国戦線III｜短期接触予測・局所投入 v1（QA限定）

2026-10-18 / 開発ブランチ `develop`。

## 目的と反証可能な仮説

直近の objectiveDirector は訓練50条件で勝敗差 -3、laneScout は拡張120条件で差0。大型ユニットへの貯蓄も敵接近で中断されるため、通常BOTの構造を全置換しない。

仮説：次の基地へ偵察ライダーを送る直前に、**公開されている敵部隊との今後6秒の接触**を低コスト推定し、危険なときだけ同じ基地へ重装工兵を送ると、前線を維持できる可能性がある。確証ではない。

### 実装

- `online-game.js` に `forecastCaptureContact(team,x,y)` を追加。指定レーンから今の `getFort` で実際に狙う基地を得る。
- 2・4・6秒後を、公開クラスの移動速度と現在の基地・城へのルートに沿って線形に予測。既存の戦闘中断や攻撃選択まではシミュレートしないため、**本当の未来位置の確定値ではない**。
- 敵と偵察ライダーの想定接触を数え、護衛の味方非占領ユニットがすでに接触点を守る場合は危険度から除外。
- 呪文、防空、大型迎撃、緊急防衛、結界という既存上位判断を守る。後段の通常捕獲判断に来たときだけ、予測危険度が2以上で、重装工兵を正規ルールで購入でき、実際の `getFort` 移動先が偵察ライダーと同じ場合に切り替える。
- 自陣営または敵陣営の非公開手札・真の資源を読まない。価格・回復率・移動仕様は無変更。
- 本候補は `forecastCapture` QA変種でのみ有効。通常BOT、対戦公開版 `main` は変更しない。

### 既知の限界

- 6秒の線形移動は接敵で立ち止まる実エンジンを過大評価する場合がある。敵が途中で目標を変えることもある。
- 工兵はライダーより遅く、危険を避けても占領速度低下で敗北する可能性がある。
- 守備的なBOTには改善しても、強襲BOTに弱くなる可能性がある。
- シードや陣営への選択バイアスを調べること。微小な訓練差なら正式採用しない。

### 検証

`tests/online-bot-forecast.cjs` に、危険2敵・無関係な敵・すでに護衛あり・資源不足・非公開手札禁止の5局面と、同一条件の通常BOTとの30組＝60試合比較を追加。

既知学習シード17/41/73、青赤、自己対戦（通常・地形反転）、rush/fortress/bankerを使う。比較では手札/初期カード順と公開エネルギーの一致、両陣営勝敗差、実発動数、消費資源、城HP、攻城ダメージ、基地保持を記録する。

CI: [BOT regression（最初の追加実行）](https://github.com/8mahi8/shokoku-sensen/actions/runs/39047207456)。
別途最新commitのrun完了を確認し、結果を追記する。初期段階の成績は不明であり、**正式採用は見送り**。

`online-game.js` と独立配置の `online-embed.html` / `online-ipad.html` は完全一致が必要。初回コミットでこの同期を怠ってオンラインsmokeが失敗したが、その後両埋め込みを同期した。修正後のsmokeの成功判定もCIで要確認。


## 第1回CIの実測と反証

[GitHub Actions #39047207456](https://github.com/8mahi8/shokoku-sensen/actions/runs/39047207456) は成功。固定局面の予測投入は期待どおりだったが、訓練用30条件（60試合）で予測チェック0、実戦変更0、勝敗差0。これは「同時にライダーと工兵を購入可能」という条件が実戦で成立しなかった（またはその前段の分岐に到達しなかった）ことを示す。強化の証拠はない。

## 第2回候補：護衛射手への分岐とゲート観測

必要基地の判定が成立する局面では、手札の偵察ライダー/工兵/射手の購入可能状態を個別に記録する。工兵が使えない場合でも、可視敵との短期接触が強く予測され、射手とライダーを購入可能なら、ライダーより先に射手を投入するQA戦術を追加。実戦で使える判断か、前線・攻城を損なわないかを同一の既知条件で検証する。通常BOTと公開版は無変更。


## 第2回CIのテスト修正

[Actions #39047605362](https://github.com/8mahi8/shokoku-sensen/actions/runs/39047605362) では旧テストが `energy=3` 時に scout を期待し失敗。新仕様では4コストの engineer は購入不可だが2コスト archer による護衛投入は合法。このため、合法な射手投入・支出2と、資源1なら一切買えないという条件を別々に検査するよう修正。実戦30組の結果は下記で確定。


## 第2回拡張テスト結果・採用判断

[短期予測専用高速CI #39047941279](https://github.com/8mahi8/shokoku-sensen/actions/runs/39047941279) 成功。固定局面では射手援護への差し替えと資源不足時の不使用を確認。既知シード17/41/73、30組＝60試合の実エンジン比較：

| 平時の予測評価入口 | 1,222 |
| 前哨基地への追加投入が必要 | 872 |
| 実際に予測を計算 | 33 |

必要基地の判定872回に対し、同時にカード・資源が揃って予測評価へ進めたのは33回にすぎない。危険局面も5回観測されたが、投入変更に必要な組み合わせが成立しなかった。初版と異なり「予測を計算できた」点は診断上の前進だが、**BOT強化は確認できていない**。

### 判断

**通常BOTへの採用は見送り**。新規未使用シードは消費しない。同じ予測閾値を緩和し続けるより、4枚の手札循環・各判断直前の資源・いつカードを切ったかを一つの時系列として再構築するべき。次は「数秒後に危険」だけでなく、資源をどのカードにいつ投資できるかという行動可能性の予測を研究する。公開版・バランス・移動AIは不変。
