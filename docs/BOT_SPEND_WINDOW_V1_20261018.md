# 小国戦線III｜短期の資源投入タイミング実験 v1

`develop` QA限定。通常BOT・公開`main`・カード性能・回復率・ユニットの移動AIを変更しない。

## 理由

前回の接触予測は、30対照条件で危険予測が5回発生しても実行可能なカードを揃えられず、通常BOTとの勝敗・城HP・基地保持の差は0だった。つまり予測の前に**手札と資源の都合**がボトルネックになっていた。

## 新仮説：小型の確定可能な窓にだけ待つ

従来の7コスト大型温存は数十秒の先延ばしと前線崩壊を起こした。これを繰り返さない。占領に必要な偵察ライダー（3コスト）が**現在の自分の4枚手札にあり**、資源が2以上3未満、現在の公開回復率で2.5秒以内に買えるなら、わざわざ先に2コストのカードを消費するより数秒待った方が早く基地を取りに行けるかもしれない。

ただし、城・基地への緊急脅威がなく、既存移動先に向けた6秒間の公開敵ユニット接触予測が無危険、さらに召喚境界付近に敵がいない場合のみ。手札にないライダーを「次に来るはず」と仮定して待たない。最長5秒の意図としてQAログに発生・成功・失敗を記録する。

通常BOTの防空・大型迎撃・緊急防衛・砲撃・結界はこの判定より先に残す。予測が悪ければ通常のカード選択に戻す。これにより予定が実行される機会が増えるという仮説であり、強化は未証明。

## テスト・採用ルール

`tests/online-bot-spend-window.cjs` は固定局面で通常BOTとの差・早期支出回避・資源3での合法召喚・手札にない場合の禁止・脅威時の中断を検査。続けて既知学習シード17/41/73×青赤×自己対戦2地形・rush/fortress/bankerの30条件を基準30＋新候補30の計60実戦で比較する。記録は `qa-bot-spend-window` に保存。

発生数が0なら「発動不能」として別の設計を考え、発生して勝率が落ちれば否定・保留、学習で明確に勝ち越した場合だけ新しい未使用シードを固定した独立評価を検討する。戦術的な採用可否は実測で判断。
