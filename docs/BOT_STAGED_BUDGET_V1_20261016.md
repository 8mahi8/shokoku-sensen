# 小国戦線III｜前線維持を前提とする資源配分候補 v1

先行の観測ログでは、30試合・3,336回の戦術BOT判断のうち、重戦車が手札にある3,025回すべてで資源不足（7未満）。前線が整い大型が手札にある状況は1,872回あったが、7コストを使えた時は0回。前線が整った状態で低コストを選んだ判断は322回。従って単なる相手の資源回復時間だけでなく、こちらの**目標優先順位と機会費用**の配分が重要。

## QA限定の仮説 stagedBudget
緊急防衛や対空・対大型・範囲攻撃等の先行判断がない場合に限り、基地1個以上確保、健康な占領可能部隊2体以上を前線に持ち、7コストの魔導重戦車が手札にある状態で、今から12秒以内に7コスト到達でき、観測敵が4コストを準備するまで4秒超なら、小型兵補充を1回見送って資源を残す。資源が7に達すれば既存の戦闘ルールで魔導重戦車を召喚。

評価条件：train 17/41/73×青赤×自己対戦通常・地形反転／rush／fortress／banker＝30対照＋30候補、総60試合。同条件の開幕デッキを固定し、勝敗・カード使用・前哨基地占領時間・城への与ダメージ・見送り回数を比較する。

これは以前の\`reserveEarly\`と別の仮説だが、攻城のために拠点攻略を遅らせる副作用がありうる。**訓練用比較で効果が無ければ採用しない**。効果があれば新しい未使用シードで対照試験を行う。正式BOTの判断・カード性能・公開mainは不変のまま。


## 第1回 train 30組（#38883608392）

CIは成功したが、初回の`stagedBudget`は固定戦況で行動差がありながら、実試合で待機0、重戦車召喚0、カード差0、勝敗差0。条件を小刻みに緩めるだけでは根本を解決しない。

## 第2回：明示的な有限期間の投資計画

同じ前線安全条件で、単発の「今何資源持っているか」に依存せず、健康な占領部隊2体・所有基地・重戦車手札を揃えた時点から最大23秒の資源投資を開始する。敵軍接近、基地喪失、部隊不足が起きれば取り消し、その後18秒は再開しない。重戦車を出せた後も14秒間の冷却期間を設け、緊急防衛や対空・対大型・防護は優先させる。これは継続的な投資計画の効果を検証する**QA限定の実験**。学習用の同じ30組に対する比較であり、未知条件での採用保証ではない。
