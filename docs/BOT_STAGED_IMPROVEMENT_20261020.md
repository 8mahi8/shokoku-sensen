# 小国戦線III｜BOT改善目標の再設定（2026-10-20）

## 本人の意図

今回の公開で「最強BOT」「強敵完成」を要求しない。公開版BOTが弱すぎて
友達とのプレイが単調にならないよう、**最初から少し手ごわくする**のが短期目標。

本格的なBOTは、後日、本人・友達が同意して集めた対人戦／対BOT戦の
匿名JSONをまとめて研究して改善する。自動学習・自動公開はしない。

## 段階1：小改善を先に公開候補へ

- 既存の合法ルールのまま、難易度設定漏れや分かりやすい行動の不自然さを修正
- オンラインのゲストBOTには既存hardの応答・判断を使用する
- オフラインの練習／ふつう／むずかしい選択は維持する
- 対戦ログ、リプレイ、大規模探索、V18演出は初回小改善の必須条件にしない
- 大規模な勝率改善を「強敵完成」と証明する必要はない。ただし既存対戦が壊れる
  明確な回帰、対人プレイの不公平、iPad/Google Sites不具合は許容しない
- 実際の学校で「前より面白い・歯ごたえがあるか」を確認して評価する

## 段階2：対戦データを集めて本格改善

- PR #14/#15 の同意制匿名ログは開発版にある。現時点で学校実機の保存・共有
  および公開反映は別途検証が必要
- 人間同士／人間対BOT、赤青、戦術、カード構成、勝ち筋・負け筋を比較
- 対戦データでの勝ち筋を無条件に正解扱いせず、独立A/Bと人間実戦で確認
- 既存BOT研究の負例（戦術ディレクター、資源温存、砦占領優先、
  未昇格PR #12など）を再利用し、同じ失敗を繰り返さない
- 真の敵手札、資源、未来行動など非公開情報を読み取るチートは禁止

## リリース運用

`develop`は`main`より多くの未公開研究・開発変更を含む。
小改善を公開するために`develop`全体を`main`へ丸ごと統合しない。
必要な変更だけを切り出し、同一リリース候補でChromium/WebKit、
Google Sites貼り付け相当、実Firebase 1vs1を確認する。

本人の明示OKまで`main`、Google Sites、本番Firebase/Rulesは不変更。
学校iPad実機での最後のプレイ評価は本人と友達が行う。
