# 小国戦線III｜既存BOTを維持した局所戦術比較 v1

## 前提

前の戦略ディレクターは50条件中改善1/悪化4、最寄り基地へ向かう変更は改善0/悪化7（青側のみ）と劣化した。通常プレイヤーの「奥の基地を狙う自由」とBOTの既存強みは変更しない。

今回は通常のカード戦術を維持し、局所的な意思決定だけを検証する（QA variant、公開mainと通常BOTは不変）。

- preemptFort：所有基地に敵が近づいていて、まだ緊急状態ではなく、味方が不足している場合だけ迎撃衛士を早めに配置する。
- escortCapturer：攻略中の占領部隊が敵と衝突しているのに護衛の射手がいない場合のみ、射手を支援として追加する。
- laneScout：追加の偵察ライダーが必要なときに、各レーンで既存の getFort に従って実際に向かう基地を推定し、敵の守備と味方の占領役の重複から行き先を選ぶ。ユニットの移動AIは変更しない。

同一学習シード17/41/73、青赤、自己対戦通常・反転、rush、fortress、bankerの30基準＋90候補合計120試合。勝敗だけでなく、自城HP・相手城ダメージ・基地保持・資源使用量・新判断発動回数を記録する。追加で三つの固定戦況におけるカード選択とレーン選択を検査する。

勝敗改善が訓練用シードで安定していなければ通常BOTに採用しない。良い候補が現れたときだけ、新しい未使用シードで最初の独立評価を行う。
