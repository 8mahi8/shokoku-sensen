# 小国戦線III｜探索型BOT V6：戦術ポートフォリオ・役割保護候補生成（2026-10-18）

## 開発目的
旧ルールベースBOTを廃棄しない。既存の防衛・対空・大型迎撃・砦占領・攻城・資源温存を合法候補の提案者として利用し、短い30Hz実戦シミュレーションで比較する研究。PGS（Churchill & Buro, 2013）、μRTSの行動抽象化（Moraes et al., 2018）を参考にしている。出典と限界は `docs/BOT_EXTERNAL_AI_RESEARCH_V5_20261018.md`。

**現時点では通常BOT、online-game.js、online-embed.html、online-ipad.html、公開main、オンライン通信を一切変更していない。** 実装はすべてlocalhost QA配信用の一時JavaScript注入・専用テスト・Actionsワークフロー。

## 実装した内容

- `tests/online-bot-rollout-portfolio.inc.js`：初手候補は既存の完全版と同じ合法なカード＋配置位置から生成。以下の異なる役割について、合法候補がある場合、各役割の上位一手を保護する：
  - `air`：飛行敵を実際に攻撃できる射手（浮遊ドローンは対空攻撃できないので対空候補から外す）。
  - `large`：大型敵がいる場合の守護ゴーレム等。
  - `ground`：地上部隊に対する迎撃衛士・守護ゴーレム・歩兵等。
  - `area`：複数の敵の制圧・範囲対応。
  - `capture`：砦の占領役（偵察・工兵等）。
  - `siege`：攻城戦車・突破役。
  - `tempo`：即時の廉価ユニット。
  - `support`：城近くの敵圧力に対する支援役。
- 待機と**既存BOTが実際に選んだ行動は必ず残す**。上記の役割上位の候補も残し、それ以外の重複候補から最大10件まで補う。役割の数が予算を超える場合は保護を優先する設計だが、今回のテスト条件では最大10件。
- 2手目は以前からの最大5候補の探索（待機＋最大4案）を使う。初手の役割保護と混同しない。
- 局面観測は敵の**現存位置と種類**、自分の資源・手札・所有砦・合法配置だけ。敵の未来の反応のシナリオ名や非公開カードを覗いて初手候補を生成しない。
- 役割ごとの迎撃距離を**対応できる敵への距離**で評価する。地上迎撃カードに飛行敵への近さを加点しない。飛行敵を攻撃できないドローンを対空候補扱いしない。これは旧24回帰中の「地上scoutとdroneが別レーンにいて守護ゴーレムの召喚位置を誤る」問題から得た一般的な修正。
- 基盤となる各候補の評価は、元の実ゲーム `tick(1/30)`、召喚合法性 `botUse`、敵の仮想反撃 `idle/counterpush/latePush` を使用。評価関数のスコア重みは現研究中に変更していない。

## 残る課題と次の行動

1. **二手目の評価近似が初手ランキングを変える原因を分離**：新規30局面の `new-13` にみられるように、正しいカードを候補に残しても、二手目の枝刈りが評価を変える。完全版との差を解明する。近似評価の改善には新しい未使用テストセットを使う。
2. **初手の探索ゲート**：将来の探索に価値がある局面（相互に合理的な防衛・攻城・占領の比較）が現れたときだけ重い探索を呼ぶ。ただし正しい有力な迎撃を見落とす場合は既存BOTへ即時フォールバックする。
3. **描画と通信の保護**：探索をメインスレッドで一括実行しない。Workerまたは処理分割や短い近似評価を検討するが、iPad Safariでの運用測定・オンラインレイテンシ回帰検証が必要。研究の評価済みスコアを実戦の勝率と同一視しない。
4. **実ゲームの数百完全試合におけるペア比較**：同じデッキ・資源・ルールと異なる相手スタイルを使い、元BOTとの勝率・城HP・砦占領時間・計算量を独立seedで検証する。初期座標など手書きの固定局面だけで通常BOTを置き換えない。
