# 小国戦線III｜BOT戦術v4 と検証（2026-10-16）

対象：開発版 `develop` のみ。公開 `main` には反映しない。

## 目的と変更

BOTをチートで強くするのではなく、人間と同じカードコスト、回復、手札4枚、回数制限、配置ライン、65体上限で判断力を高める。

1. **拠点防衛**：自軍基地周辺の敵・味方の数から、基地の奪回危険を検出。城が迫られている場合や基地が攻められている場合は、防衛を大型召喚のためのエネルギー貯蔵より優先する。
2. **役割別の迎撃**：接近した飛行ユニットに対して対空射手を配置し、敵大型ユニットに対して守護ゴーレムで対応する。ただし近くに既に同じ対処役がいる場合は重複を避ける。
3. **時間差砲撃の予測**：1.3ゲーム秒の遅延砲撃に対し、敵が移動していれば速度と向きを控えめに外挿して着弾位置を決定。実際の移動を完全に予知することはできない。未着弾の砲撃と同じ場所への無駄な重複を抑える。
4. **防護結界の使い方**：危険にさらされた味方が複数いる場合に選ぶ。すでに同じ場所をカバーしている有効な結界との重複を避ける。
5. **エネルギー計画**：安全な場面だけコスト7の大型召喚を狙う。拠点を攻略する部隊が不十分な時は、先に偵察ライダーや重装工兵を召喚する。攻撃されているのに貯め続ける振る舞いを修正。
6. **準備中のリトライ**：手札と資源が使用できない瞬間に1回だけ配置を試みて永遠に諦める問題を防ぐ。成功した時のみ準備済みとみなす。

難易度は、練習（従来の簡易ランダム主体）、ふつう（戦術BOT）、むずかしい（より頻繁に考え、2体の密集敵にも範囲攻撃を使える）の3つを維持する。

## 実装とテスト

ゲーム本体：`online-game.js`。Google Sites向け `online-ipad.html` と `online-embed.html` 内蔵スクリプトにも同じ修正を反映した。

専用テスト：`tests/online-bot-tactics.cjs`。一般の開発版ページと学校iPad向け単体HTMLで、実際の戦闘関数と同じ `playCard` を使った8種類の戦況を確認する。

- 密集した進軍への遅延砲撃と正しい資源消費
- 飛行部隊への対空迎撃
- 敵大型への守護ゴーレム
- 保有基地が襲撃された際の範囲迎撃
- 危険な味方複数への防護結界
- 危機のない場面での大型用エネルギー蓄積
- 貯めた7以上の資源を使う大型召喚
- 通常難易度が2体密集に範囲砲撃を乱発しないこと

従来のFirebase 1vs1本物通信テスト・オフラインBOT・iPad操作・130体負荷テストを同時に回帰確認する。

## 残る課題

本テストは戦術上の明確なケースに正しく反応するかの検証であり、**平均勝率や対人勝率の向上を実証したものではない**。100～1000試合規模の自動模擬対戦と強さ別の勝率・行動・資源分析は次の段階。実機での対人プレイでも反証が必要。
