# 小国戦線III｜敵資源の回復予測とBOT対戦（train-only）

前研究で、敵の公開カード使用履歴と既知の資源回復速度から、敵の現在資源を実値と一致する形で復元できた。しかし既存の戦術BOTと通常スクリプト相手では資源4/7を貯める敵が少なく、現在残量に基づく単純判断は勝率を改善しなかった。

今回の狙いは **相手が何秒後に2/4/7エネルギーへ達するか** を試合開始からの実時間と回復段階（0–100秒:0.25/s、100–210秒:0.36/s、210–270秒:0.53/s、それ以降:0.7/s）に基づいて算出し、局面の変化を試すこと。敵の非公開手札や真のエネルギーを覗かず、\`S.observedEnergy\`を使う。

## ゲームのルールは変更しない
- コスト、HP、ダメージ、資源回復率、召喚可能位置、手札、戦闘AIは全て据え置き。
- 試験専用の\`secondsUntilAffordable()\`を用いた予測と\`tempoSiege\`、\`tempoScreen\`方策は **localhost ?qa=1 の候補のみ**。通常のBOTには採用しない。
- `tempoSiege` v2：占領済み基地と前線部隊があり、敵が7秒以内に4資源、15秒以内に7資源を回復できないと推定される場合のみ、ドローンで早期突破を試す。無条件な大型貯蓄を廃止した。
- \`tempoScreen\` は敵が4コストを5秒以内に確保でき、実際に敵軍が自分の召喚線へ接近している場合のみ迎撃衛士で予防。敵不在時の空回りを禁止。
- \`banker\` は公開カードルールに従う開発用スクリプト相手。緊急防衛以外では7コスト大型まで貯めるので、現行の資源消費型相手に無かった高資源状態が再現できる。
- 基本3シード×4相手スタイル×通常・高速×青赤=48対照試合。候補2×48=96比較試合。計144試合。未使用の評価用シードには触れない。

## 判定と反証
予測の各回復段階境界を数式で検査し、カードから復元した資源との一致、相手の保有時間、候補の発動件数、カード消費・基地保持・城HP・勝敗を記録する。勝敗改善がない候補は標準BOTへ入れない。基準を満たしそうな候補のみ、**別の完全未使用シード**を事前に固定した独立試験で検証する。

この評価は実機対人の強さを保証しない。性能値の調整・\`main\`の変更は今回の範囲外。


## 第1回実測と仮説の修正

[Actions #38880732589](https://github.com/8mahi8/shokoku-sensen/actions/runs/38880732589) では144試合と境界計算が成功。banker は平均約20.9秒にわたり資源7以上を保持した。一方、初版の tempoSiege は14回「温存」判断したものの、試合中のカード使用は変わらず、tempoScreen は発動0。勝敗差はいずれも0。

第2版では、資源予測を実際のカード選択に結びつけるためドローン早期投入へ変更し、固定戦況で通常BOTと候補が異なるカードを選ぶことも自動検査する。これも train-only であり、正式BOTへはまだ採用しない。
