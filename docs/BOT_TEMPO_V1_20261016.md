# 小国戦線III｜敵資源の回復予測とBOT対戦（train-only）

前研究で、敵の公開カード使用履歴と既知の資源回復速度から、敵の現在資源を実値と一致する形で復元できた。しかし既存の戦術BOTと通常スクリプト相手では資源4/7を貯める敵が少なく、現在残量に基づく単純判断は勝率を改善しなかった。

今回の狙いは **相手が何秒後に2/4/7エネルギーへ達するか** を試合開始からの実時間と回復段階（0–100秒:0.25/s、100–210秒:0.36/s、210–270秒:0.53/s、それ以降:0.7/s）に基づいて算出し、局面の変化を試すこと。敵の非公開手札や真のエネルギーを覗かず、\`S.observedEnergy\`を使う。

## ゲームのルールは変更しない
- コスト、HP、ダメージ、資源回復率、召喚可能位置、手札、戦闘AIは全て据え置き。
- 試験専用の\`secondsUntilAffordable()\`を用いた予測と\`tempoSiege\`、\`tempoScreen\`方策は **localhost ?qa=1 の候補のみ**。通常のBOTには採用しない。
- `tempoSiege` v2：占領済み基地と前線部隊があり、敵が7秒以内に4資源、15秒以内に7資源を回復できないと推定される場合のみ、ドローンで早期突破を試す。無条件な大型貯蓄を廃止した。
- \`tempoScreen\` は敵が4コストを5秒以内に確保でき、実際に敵軍が自分の召喚線へ接近している場合のみ迎撃衛士で予防。敵不在時の空回りを禁止。
- \`banker\` は公開カードルールに従う開発用スクリプト相手。緊急防衛以外では7コスト大型まで貯めるので、現行の資源消費型相手に無かった高資源状態が再現できる。
- 基本3シード×4相手スタイル×通常・高速×青赤=48対照試合。候補2×48=96比較試合。計144試合。未使用の評価用シードには触れない。

## 判定と反証
予測の各回復段階境界を数式で検査し、カードから復元した資源との一致、相手の保有時間、候補の発動件数、カード消費・基地保持・城HP・勝敗を記録する。勝敗改善がない候補は標準BOTへ入れない。基準を満たしそうな候補のみ、**別の完全未使用シード**を事前に固定した独立試験で検証する。

この評価は実機対人の強さを保証しない。性能値の調整・\`main\`の変更は今回の範囲外。


## 第1回実測と仮説の修正

[Actions #38880732589](https://github.com/8mahi8/shokoku-sensen/actions/runs/38880732589) では144試合と境界計算が成功。banker は平均約20.9秒にわたり資源7以上を保持した。一方、初版の tempoSiege は14回「温存」判断したものの、試合中のカード使用は変わらず、tempoScreen は発動0。勝敗差はいずれも0。

第2版では、資源予測を実際のカード選択に結びつけるためドローン早期投入へ変更し、固定戦況で通常BOTと候補が異なるカードを選ぶことも自動検査する。これも train-only であり、正式BOTへはまだ採用しない。


## 第2回学習試験の反証（#38881262661）

固定戦況では予測とカード選択の差が成立しテストも成功したが、実際の144試合では tempoSiege・tempoScreen ともに発動0、勝敗差0。候補を正式BOTへ採用しない。

第3回の学習案では、攻城条件を「基地確保、味方1体以上、生きた前線、非緊急防衛、ドローン手札あり、自軍資源4以上、敵が4資源へ到達するまで6秒超」に絞る。限定局面を前提としながら、実戦で行動を変えられるかを調査する。基地確保・手札・必要資源・安全条件の観測回数も出す。これでも変更が生じないなら、単純ルール追加を止めて判断順序そのものを調べる。


## 第3回 train-only 試験（#38881686154）

[Actions #38881686154](https://github.com/8mahi8/shokoku-sensen/actions/runs/38881686154) で、回復時刻・既存戦術・新規144試合の全試験が **SUCCESS**。

| tempoSiege v3（6秒以上敵の4資源回復を待つ条件、ドローン優先） | 48 | 0 | 0 | 0 |
| tempoScreen（実際に接近する敵がいるときの先行迎撃） | 48 | 0 | 0 | 0 |

* 単独判定として「基地所有」2509回、「ドローン手札」477回、「ドローン4コスト支払可」225回、「守備に緊急性なし」2020回を観測（48試合における思考機会の各個別判定合計、**相互に重複可**）。これらが同時に重なる機会がまだ見つかっていない。各判定の数字を掛け合わせて確率や成功率と見なしてはいけない。
* 敵資源を7以上貯める **banker相手**も導入済み。対照12試合ではゲーム内平均20.88秒にわたり敵資源7以上を観測。通常対戦相手には存在しなかった回復・貯蓄局面を再現できた。
* 数学的な資源回復ETA・初期資源＋実コストの台帳一致・実ゲームの戦闘回帰は成立。
* 固定局面のテストでカード選択が変わる一方、実際の144試合では変わらない。**「予測式の正しさ」と「意思決定の有用性」は別**で、全候補の正式BOT採用は保留。

### 次の作業方針（同条件での追加チューニング禁止）

似た閾値をさらに緩める行為は、今回の狭いtrainシードへの過適合になりやすい。ここで閾値調整は止め、先に **判断順序と機会費用** を分析する。

1. 実際の行動直前にBOTが選び得た候補カードと、不採用理由（費用不足、手札なし、防衛優先、前線位置、相手の反撃ETA）をまとめて採取する。
2. 自軍資源を無条件に貯めると以前の未知評価で悪化した事実を維持し、単純な資源温存ルールには戻さない。
3. 敵が何秒で反撃できるかに加え、味方の移動時間・部隊生存見込み・相手の既存戦力を比較し、意思決定の順位付けを設計する。
4. 次候補が意味のある train 比較差を示してから、未使用シードで独立評価する。既に観測した train 17/41/73 と過去の holdout は新しいholdout扱いしない。

現状では勝率向上なし。コードには QA用の予測器・高資源相手・テスト基盤のみ保持し、**標準BOTの戦術、公開main、ゲームバランスは変更していない**。
