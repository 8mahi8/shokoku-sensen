# 小国戦線III｜探索型BOT v0.3｜6秒後の合法な第2手を探索する

2026年10月18日。探索型BOTの研究専用QA。ユーザーからの「任した」に基づく既存ルールベースBOTの次段階。**通常BOT／公開main／オンライン実装／カード性能を一切変更せず**、localhostの一時スクリプト注入でのみ動作。

## 研究経緯：以前の実験はどこに生きているか

- 「大型用に貯める」「2コスト歩兵を追加する」「砦を一つ捨てる」などは一律ルールだけで高勝率を保証できない。特に`captureSpendGate`は既知学習120比較でネット+6だったが独立holdout200比較では**-18**で不採用。新しい二手探索も、固定訓練シードで良さそうだからと通常BOTへ昇格してはならない。
- 「瞬間的な基地保有時間」と「城HP・敵城への攻撃損害・勝敗」は一致しない可能性があり、評価スコアには城HPと基地時間の両方を持たせる。
- 一手探索（v0.1）では初手カードだけでなく**配置座標**を比較したことで、同じ迎撃衛士でも敵突破を阻む適法な出撃点が見つかった。
- 敵の仮想反応に備える複数シナリオ（v0.2）と、8／20／32秒で結果が変わる研究が、二手探索の**反証条件**となる。
- 今回は初手を終えてから6秒で手札・資源・目の前の敵部隊・所有基地を再読込して**2手目の選択肢**を実際に比較する。固定の「次に歩兵を出す」ルールを付け足すのではない。

## 実装・保護範囲

`tests/online-bot-rollout-two-step.inc.js`：既存のv0.2と同じ実エンジン`tick(1/30)`、30Hz攻撃・移動・城・砦・資源、実際の`botUse`による合法なカード購入・手札回転・配置制限。初手は従来BOTの行動、手札から現在払えるカード（スペル除く）、常設基本歩兵、待機、複数の合法な配置点を比較。

敵の未来は、自作の公開仮説 `idle`／`counterpush`／`latePush`。`counterpush`は+3秒と+9秒に合法な進軍カードを使用し、`latePush`は+3秒は何もせず+9秒に初めて使用する。両者は非公開の敵手札を読むのではなく、**公開カード種類から固定された仮想手札**を用いる。

+6秒時点で、自分が観測できる現在の敵ユニット、基地、味方の現在手札、使用可能資源だけから第2手を新規生成。待機、合法な低コスト・占領・攻城・防衛ユニット、現在の相手の位置と進路に合わせた迎撃配置、実際に払える砲撃・結界などのスペルも検討する。

第2手は同じ現在局面を毎回複製して、+6秒から探索全体の終端までの**残り14秒**を3D描画無しの実エンジンで回し、仮評価スコアを比較して選択。**+9秒の敵の予定行動や反撃パターンの識別ラベルを第2手探索に渡さない**。選択した第2手を実際の候補分岐世界に戻して合法なコストで購入した後、元々の敵反応+9秒を実施し、20秒終端の全局面を採点する。

初手の採択は、3つの敵反応パターンのうち最も悪いスコアを最大化し、同点時は平均・コストで比較する。城HP、敵ユニットダメージ、砦保持秒、既存味方の損傷、新規味方の残HP、**初手と第2手両方のコスト**を使う。重みは既存の暫定評価を維持し、既知場面に合わせて後付けで調整しない。

`tests/online-bot-rollout-two-step.cjs` と `.github/workflows/online-bot-rollout-two-step.yml` からPlaywright QA。3局面（序盤占領、地上突破、既存の防衛兵と敵突破）×既知seed17/41×3仮想敵反応×初手選択肢6〜13を測定。一手探索と二手探索の**初手候補集合が同じ**こと、二手目の正規支出、ランダムシード再現性、合法性、敵の進軍反応が実際に出ることを検証。

## 成果：2手目が実際に変化した

最初の成功：[Actions #39125739184](https://github.com/8mahi8/shokoku-sensen/actions/runs/39125739184)。
+6秒からの評価を残り14秒へ延ばして現実の占領移動を反映：[Actions #39125831445](https://github.com/8mahi8/shokoku-sensen/actions/runs/39125831445) 成功。
時間差を設けた敵未来 `latePush`を追加し、6秒時点で区別できない2未来から**完全に同じ第2手が選ばれる**ことを毎候補・seedで検証：[Actions #39125955298](https://github.com/8mahi8/shokoku-sensen/actions/runs/39125955298) 成功。
最終の遅延敵召喚が実際に実行されることも含めたCIは別途確認し、成功の場合のみ受け入れる。

最初の3局面、同じ開始手札・資源・ランダムシードの比較において、初手最上位は一手探索と二手探索で一致した。ただし**敵の+3秒の行動を見て、第2手の判断が分岐**した：

| QA固定局面 | 敵の+3秒までの反応 | +6秒の第2手 |
| --- | --- | --- |
| 序盤占領、初手=歩兵 | 敵増援なし | 待機 |
| 同上 | +3秒の敵進軍 | 偵察ライダー3コスト |
| 城前地上敵、初手=衛士を正しい進路に置く | 敵増援なし | 待機 |
| 同上 | +3秒の敵進軍 | 魔導射手2コスト |
| 守備兵がいる敵突破、初手=射手 | いずれも | 待機 |

いずれも初手から20秒、+6秒に第2手を再評価。差分は「相手が攻めそうだから決め打ちで出す」ではなく、**見えた盤面から第2手候補を再生成し、残り14秒を再シミュレーション**した結果。同じ局面の `idle` と `latePush` は+6秒にどちらもまだ敵増援を見ていないので、両方とも同じ選択になった。

厳密には現時点の二手探索は、**実プレイヤーが戦う1試合に適用されたBOTではなく、QA局面の初手+第2手を比較するプロトタイプ**。実際の勝率に対する優位性は未検証。

## 本番採用しない理由／次の工程

1. 処理時間：GitHub ActionsのLinux Chromium環境では、3場面（1手版＋2手版＋再実行）の処理が場面ごとに約0.8〜3.5秒かかる。これは**iPadで瞬時に判断できる保証がない**。探索幅・優先候補数・考慮するユニット数を絞り、決定時間を事前予算化する必要あり。
2. 相手の隠れたデッキは知らないため仮想手札を用いている。複数の反応パターンを持たせたが、完全な人間心理の再現ではない。
3. 第2手のサブ探索ではさらに未来の追加敵召喚を一時停止している。+9秒の本体外側シミュレーションでは合法な敵反応を再開。敵の次手が未観測でも第2手を変更しないことは検査済み。
4. 固定3局面、既知2seed。自己対戦・rush・bankerなどでの完全な30Hzゲーム数百試合比較は未実施。旧BOTより勝てるか不明。
5. スコア関数は手で設定した暫定値。相手の城が落ちるまでの戦略的な価値、長期の砦奪還、資源の機会費用を十分に評価できているか未確定。

したがって、**通常BOTと公開mainへの導入はしない**。この新しい二手分岐の実装を土台として、次は合法性とレイテンシを守る探索候補の剪定と、実戦対照ペアを優先する。
