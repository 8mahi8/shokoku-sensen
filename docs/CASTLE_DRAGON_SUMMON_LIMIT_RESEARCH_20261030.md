# 小国戦線III｜『城とドラゴン』召喚数の決定原理調査（2026-10-30）

## 調査目的と結論
本人の質問：「城ドラってどうやって召喚数決めてるかの方が大事じゃない？そこを調べてきて欲しい」。
公開資料に、**城ドラ運営の正式な「召喚数決定式」や内部の採点表は確認できない**。以下は非公式プレイヤー研究・キャラデータ・調整履歴からの推論であり、公式決定方法と断言しない。

重要な設計知見：
1. **資源の試合総供給**を基準に、1デッキの「コスト×最大召喚数」を集計。個々の回数だけでなく、デッキ全体の使い切り・残りすぎを確認する。
2. 同じコストでも最大召喚数は異なる。戦闘性能だけでなく特殊効果、役割（壁・前進・回復・大規模な盤面変化）を考える仮説を持つ。ただし付加価値の重みは本人と検討し、現行BALANCE-SOPのStep A「純数値比較」と混ぜない。
3. 召喚数はHP・攻撃力に並ぶ調整項目。2023/01/20のチビピク実例は最大召喚数3→4と同時にHPを6.4%減らしている。
4. 城ドラ側の中型を対象とする攻略研究は1枠約10～12コスト（3分間試合で70～71総コスト、剣士・大型を別途消費）と推計する。**これは開発者公式の設計基準ではない**。
5. デッキ全体が薄いと強力な通常カードを早期に使い切って剣士しか残らず、厚すぎると召喚枠が余る。攻め切るデッキとの相性は戦術なので一律是正はしない。

## 現小国戦線IIIとの定量比較
データ：開発ブランチ online-game.js 2026-10-30。
- 300秒試合。エネルギー自然回復量 = 0–100s(0.25/s) + 100–210s(0.36/s) + 210–270s(0.53/s) + 270–300s(0.7/s) = **107.4**。初期8と合計理論最大 **115.4**（エネルギー上限12、溢れや未使用は未考慮）。
- 現行固定のデフォルト10枠は各カードの「**コスト×残りの使用回数**」の総計が以下。
  scout 3×5=15; engineer 4×5=20; archer 2×8=16; barrage 4×3=12; sentinel 4×5=20; suppress 5×6=30; guardian 7×2=14; ward 3×3=9; drone 4×5=20; tank 7×2=14; 合計 **170**。この数値は基本歩兵（無制限）を除く。
- つまりデフォルトデッキの有限カードだけで、試合全体の理論資源最大115.4より**54.6多い**。各カードを満遍なく使うと個別の上限に届きにくい構造。これが『上限が空気』の有力な原因（実プレイの使用率統計ではない）。
- 一方で、10種のうち1種を繰り返し使う戦術なら、そのカード上限に先に当たる可能性はある。
- **小国のドローンは1カード4資源で2体召喚**、上限5は「5回・累計10体・有限予算20」。城ドラの体数と小国の召喚操作回数の定義を混同しない。

## 次の設計手順（未承認／ゲームコード変更なし）
1. 各カードの純戦闘力/コスト比較はBALANCE-SOP v1.2どおり全コスト帯で実施（本人の最終判断を代替しない）。
2. 全10枠の有限使用可能予算（Σコスト×使用回数）を試合総資源115.4、常時枠基本歩兵に使う分、カード選出頻度と対比する。参考仮説：基本歩兵に10～20資源使用するなら残り95～105を10種類で平均約9.5～10.5（平均であって全カードが同じになることを意味しない）。有限枠の合計が小さすぎると終盤が基本歩兵だけになりうる。
3. 単純な最初の試案：コスト2→4～5回、3→3～4回、4→2～3回、5→2回、6～8→1～2回を叩き台に、キャラ個別の役割、複数体召喚、占領、特殊能力、スペルの代替不能性を本人と議論。**ここに並べた回数は未承認、決定値ではない**。
4. デフォルトデッキだけでなく低コスト偏重/高コスト偏重/対空薄め/スペル多めのカスタム10枠をテスト。試合半ば/終盤の欠品率、残存カード数、使い切るタイミング、基本歩兵だけになる割合を記録して調整。厳格な数式固定を採用しない。
5. 本人の合意後に limit のみ最小変更してテスト・Docs更新。**勝手に新システム化しない**。
