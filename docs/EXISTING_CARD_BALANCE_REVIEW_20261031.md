- 機械召喚師の小型機が**全8体生き残る仮定**なら合計基礎DPS `7.89 + 8×9.33 ≈ 82.56`、合計HP本体340+子8×85=1020。ただし**生成まで31秒必要**で、実戦では撃破・範囲攻撃・移動・攻撃先・65体制限に左右される。6秒経過・3子機生存でも合計DPS約35.89。本体のみの低さで即強化を断定しない。
- 現行の`POST_HP=12`、重装/遠距離とも占領攻撃2／間隔1.4秒なので、妨害なし・初撃0秒なら砦制圧に6発・7秒（移動時間別）。**重装が遠距離より速く占領できるわけではない**。
- 範囲砲撃が1体だけに当たると合計125/4コスト、2体なら250/4、3体なら375/4の総ダメージ（過剰ダメージ除外前）。125ダメージは無軽減のHP95射手、105基本歩兵、120ドローン、小型機85には単体撃破閾値。半径82の**最終着弾位置判定**のため速い相手へのミスがあり得るが、発生率は実測していない。

## 3. AIの提案（**未承認・未実装**）

1. **機械召喚師**：単純に本体HPや子機攻撃力を大きく増やすより、早期に戦力が出るかを先に評価。仮案は子機の初期生成時刻を `2,4,6秒 → 1,3,5秒` とする。後半の11/16/21/26/31秒と最大8体は据え置き。強すぎる長期スケーリングを避ける意図。決定ではない。
2. **範囲砲撃**：ダメージ125を維持し、まず予告から着弾まで `1.3 → 0.9秒` の試遊案。速い敵への空振り問題へ直接対応。さらに強化したい場合でも半径・コスト・上限を同時に変更しない。
3. **重装工兵**：射程やAIを入れ替えず、耐久の差別化で `HP420 → 480` を最初の比較候補にする。仮想対面では**制圧機兵に逆転して重装残HP30、15.4秒**（実戦は制圧の射程/範囲/対空が有利）。この閾値を超えるため、過強化の可能性も本人に伝える。迎撃衛士との前提差も考慮。
