# 前哨基地の戦況表示・ワンタップ移動（開発版）

対象：`develop`。公開版 `main` は維持。

## 目的

小国戦線IIIでは画面を左右に動かして戦うため、前哨基地がどの勢力のものか確認するのに手間がかかった。画面上端に情報量の少ない小型の戦況表示を追加し、タップ一回で目的地にカメラを移せるようにする。カードバトルやリアルタイム戦略ゲームに共通する「戦況と操作を見分けやすくする」という設計に基づく変更で、既存作品のUIや素材のコピーではない。

## 仕様

- 左上に基地の青軍占領数・赤軍占領数と、前哨基地1～3の状態を表示する。
- 基地の所有者：中立・青軍・赤軍。青軍は青色、赤軍は赤色の枠・背景で表示。
- 基地の周辺に青軍・赤軍が両方いると「争奪」状態を明示。
- 所有基地に敵が近づくと「警戒」、他勢力・中立基地に接近すると「攻略」と表示。
- 「争奪」「警戒」「攻略」は周囲の生存ユニットから求める近接状況。攻撃が発生したことや、占領が保証されたことを表すわけではない。
- 各基地のボタンをタップするとカメラが当該基地に滑らかに移動する。使用中のカード選択はそのままで、タップを誤って召喚として扱わない。
- 対戦準備中と戦闘中のみ表示。結果画面、ロビーや図鑑の操作を妨げない。
- 表示は既存のシミュレーション状態`S.forts`と`S.units`を使い、Firebase通信の新規フィールドを追加しない。青軍と赤軍の表記はどちらの端末でも共通。
- レイアウトはiPadの横/縦・コンパクトなGoogle Sites埋め込みを対象にした最低限のコンパクトなサイズ。

## 品質検査

`tests/online-fort-navigation.cjs`でChromium/WebKitの両方の3表示（計6件）を自動確認。ロビーでは非表示、戦闘準備中に表示、占領数・争奪・青赤ラベルの更新、実タッチでのカメラ移動、カードを選択したままボタンを押しても誤召喚しないことを検証する。

既存の`online-ipad-ui.cjs`、`online-offline-bot.cjs`、`online-touch-interaction.cjs`、`online-mass-battle.cjs`、`online-grand-arrival.cjs`と並行して回帰テストする。オンライン2画面テストとsmokeも維持。表示のわかりやすさやタッチ感覚の最終確認には実機iPadが必要。
