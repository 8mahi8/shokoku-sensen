# 大型カード登場演出｜シャドバ演出を参考にした開発版の検証

記録：2026-10-16。対象リポジトリ `8mahi8/shokoku-sensen` の **develop ブランチ**。安定版 `main` を変更しない。

## 参考と設計原則

ユーザーの提案：シャドウバースでは強力なカードを使用した際、画面全体の雰囲気が変わる。小国戦線IIIの対戦中にも、強力なユニットの登場を印象づける。ただし性能低下と戦場の視認性を重視。

- シャドウバース ワールズビヨンド公式のカード説明は、フルアートカードにバトル中の特別な演出があると明記する：<https://shadowverse-wb.com/ja/cards/pack/blossoming-fate/>
- 簡易演出やモーション低減の設定が存在する点は参考になる：<https://gamewith.net/shadowverse-wb/68449>
- オリジナル作品の演出・音声・画像をコピーせず、重要なプレイに視覚的な区切りを設ける**抽象的な設計**だけを学ぶ。

## 開発版で実際に変更したこと

- コスト7の**守護ゴーレム**と**魔導重戦車**を使用した際、約880ミリ秒だけ戦場Canvasの雰囲気が変わる。
- 自軍の大型ユニットは青い淡い光、敵軍の大型ユニットは赤い淡い光で画面全体を一瞬包む。
- 戦場の輪郭と、画面内の登場地点に広がる衝撃波を重ねる。画面外への召喚なら地点は描画せず、軽い画面色変化だけで知らせる。
- 通常の歩兵・小型・中型カードには適用しない。連続して大型が登場した場合は最新のユニットを優先する。
- ポインター操作・タップ・スワイプやカメラ操作は従来どおり。DOMレイヤーの追加、画面揺れ、ブラー、操作停止、ゲーム時間の停止は一切行わない。
- reduced-motionが指定された端末では強度を28%に抑え、登場地点の衝撃波を描かない。
- 既存のworld.unitsから新しく登場した大型ユニットを検出する。Firebaseに新たなイベントやデータ構造を追加しない。
- ホストとゲストのローカル時刻はずれることがあるため、時刻比較は行わず、同じ試合中に新しいユニットIDを受信したかを検出する。
- 対戦開始時に既にいる大型ユニットは検出済みとして扱い、入室直後やリマッチ時の誤った再生を抑制する。

## 注意点と次に確認すること

1. PC上のheadless Chromium/WebKitでの描画確認であり、学校のiPad Safari実機のFPSや体感は再現しない。
2. 130体の高負荷下でさらに重くなる可能性があるため、全画面フィルタや高頻度のパーティクルは採用していない。
3. 開発版で見た目を調整できる。最終判断では演出の強さが戦術操作を妨げないか、実機での短い試遊が必要。
4. この演出は見た目のみで、ユニットの強さや勝敗、通信挙動に影響しない。
