# 一台ゲストテスト｜実Firebaseの赤軍ゲスト描画を自分で確認

開発用：`guest-lab.html` を開き「テスト開始」。同じタブで小さな青軍ホストと大きな赤軍ゲストを別iframeとして動かし、通常の `shokokuRooms1v1` RTDBルームで接続する。ホスト側は既存の `botExpertAction(1)` を使って青軍のカードを自動操作。赤軍は本人操作の実ゲストコードを通る。対戦終了またはやり直しで戻る。

- 学校で使用中のGoogle Sitesに貼ったHTMLも、mainのオンライン対戦コードも変更しない
- **1台のホスト＋ゲストは2台対戦より処理負荷が大きい**。フレーム時間は実機本番の再現ではなく、カクつく歩行/補間・実通信を何度も評価するための簡易環境
- Firebaseへ試験ルームを作るのでネットワークが必要。無料枠を超える使用や本番運用の負荷試験に利用しない
- 検証: `tests/online-guest-lab.cjs` のChromium・WebKitでルーム生成/2人接続/青BOT実戦/赤ゲスト受信/再試行/テストルーム削除。試験で使う公開RTDBルート以外へは書き込まない
- devブランチで検証後、GitHub Pagesに追加する時はこの2ファイルだけを main に追加し、既存の公開ページを上書きしない
