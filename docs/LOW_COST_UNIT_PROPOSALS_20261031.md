## 第1次キャラクター案

### A. 先遣走兵（1コスト）

| 項目 | 仮数値 |
|---|---|
| 価格／1回体数／試合使用上限 | **1／1体／5回**（総出撃予算5） |
| HP／攻撃／間隔 | **80／14／1.20秒** |
| 移動速度／射程／索敵 | **44／29／112** |
| サイズ／移動タイプ／行動型 | 小型・地上・占領型 |
| 占領／対空／範囲 | 1／不可／なし |
| 対象優先度 | fort:3、castle:2、unit:1 |

- 狙い：最速クラスの移動で砦へ先着しやすい、しかし耐久が極めて低く占領自体は遅い。敵部隊がいない隙に使うかどうかが重要。純戦闘力は低い。
- 基本歩兵（2コスト・2体・105HP・15ダメージ／体）や偵察ライダー（3コスト・195HP・28ダメージ）との差別化は**移動速度と1コスト**で行う仮説。独自特殊攻撃なし、共有AI使用。
- リスク：1コストで手札を安く回せるため、砦の価値よりカードサイクル目的だけで選ばれる可能性。上限5回で影響を抑え、試遊判断。
