# 小国戦線III｜Stage 3 開発ブランチ実装・検証・引き継ぎ
2026-10-30｜本資料は現在の実コードに追従。ユーザーによる「今のバランスでよい」を採用の合図として開発版へ反映。

## 現在の実装
- **大型 砦進撃怪獣 (`kaiju`)**：6コスト／HP1000／攻撃72／2.25秒／速度22／射程40／索敵220／占領3／使用2回／1体召喚。地上・単体近接・対空不可。優先度は **砦4＞城2＞敵兵1**。視界内の合法な砦を狙うときは射程内の敵兵に反撃せず、砦攻撃HP12を4回で占領。砦が視界外の場合は従来AIに従い敵兵を攻撃できる。全域索敵や後方への追撃は追加しない。
- **疾風号令 (`gale`)**：3コスト／使用3回／発動半径125。発動時に半径内の生存中の味方ユニットだけへ、移動速度×1.5を4秒間付与。**発動円から出ても継続、後から範囲に入った兵士は対象外**。スピード以外の攻撃間隔・攻撃力・AIは変更しない。敵ユニットは対象外。
- **小さな共通状態レイヤー**：`applyStatusEffect`、`tickStatusEffects`、`effectiveMoveSpeed` を `online-game.js` に実装。各ユニット`statusEffects:[{key,stat,mult,remaining}]`。同keyは非重複・再付与時残り時間を更新。異なる移動補正は乗算。現行引力の移動拘束・防護結界のダメージ軽減は変えない。ホストが持つ`world().units`経由でゲストに同期可能なデータ構造にしたが、新機能を含む実Firebase両席試験は別途必要。
- **既存大型の承認済み調整**：守護ゴーレムHP1400→**1300**、魔導重戦車HP1100→**1000**。それ以外の既存大型AI、範囲、攻撃力・クールダウンは不変。
- **見た目**：`v3-art.js`へ怪獣用のオリジナル横向き大型シルエットと疾風号令のカード用アートを追加。`online-game.js`でバフ中の味方に矢印マーカー。混雑時の大型キャッシュ・HP表示高さ・登場演出に怪獣を追加。学校用候補の単体HTML2種（`online-ipad.html`/`online-embed.html`）を開発ブランチでのみソースと同期。
- **デッキ**：新カードは既存の`CATALOG`経由で選べる。選択10種類＋基本歩兵常設、既存デッキ保存・ルールを変更しない。
