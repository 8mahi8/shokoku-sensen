## 1. 3枚の仮設計

### 1-1. 衛生補助兵（デッキ用小型・味方回復／コンセプト採用済み）

| 項目 | 第1次仮値 |
|---|---|
| コスト／召喚体数／上限 | **2／1体／4回**（最大出撃資源8） |
| HP／単発攻撃力／攻撃間隔 | **180／10／2.00秒** |
| 通常攻撃射程／索敵 | **30／115** |
| 移動速度／当たり半径／サイズ | **16／13／小型** |
| 行動／占領／対空 | **guard（配置地点を守る迎撃型）／0／不可** |
| 対象優先度 | `castle:0,fort:0,unit:2`（既存共有優先度を使用） |
| 回復範囲／量／間隔 | **本人を中心とする半径90／傷ついた味方1体へ20HP／2.00秒** |
| 初回回復／対象選択 | **召喚2秒後**。HP率が最も低い傷ついた味方1体（同点は安定ID順） |
| 回復可能な対象 | 味方の生存ユニット（地上も飛行も可、他の衛生補助兵も可）。**自分自身、城、砦、撃破済ユニットは不可** |
| 回復の上限 | 対象の本来の最大HPまで。範囲外では回復なし。撃破で停止。複数衛生補助兵の回復はそれぞれ通常判定（重複上限を勝手に新設しない）。 |
| 攻撃と回復の関係 | 2秒ごとの回復は**通常攻撃とは独立**。敵がいなくても傷ついた味方がいれば回復。 |
| タッチ操作 | **普段通り自軍召喚可能エリアに1タップ配置**。配置地点を守り、味方の継戦を助ける。 |

- 1コスト当たりの単体HP=90、DPS/コスト=`10/2/2=2.5`。基本歩兵（2コストでHP105×2、攻撃15×2、間隔1.45）と比較すると、素の総HPは180対210、総攻撃DPSは5対約20.69。**サポート効果で補わなければ直接戦闘は大きく弱い**。
- 回復の計算例：対象がずっと傷ついているなら1体あたり最大**10HP/秒**相当。10秒生存して5回すべて有効なら合計100HP、30秒間で15回すべて有効なら合計300HP（実戦では無傷・範囲外・死亡・治療不足により低下）。
- 防護結界は3コストで半径93に5.2秒・被ダメ45%軽減。こちらは2コストの1体召喚で長時間・単体回復するが、**敵の一撃死を防ぐ即時軽減はできない**。死亡直前に回復周期が間に合わなければ無意味。
- 想定弱点：射程と移動速度が低い、基本歩兵や射手の正面戦に弱い、敵の広範囲攻撃では支援兵ごと倒される。攻撃対象と回復対象を独立したタイマーで扱う簡素な実装を検討。
- 重要な未検証：guard行動の索敵円や配置座標から味方回復範囲が機能するか、味方による遮蔽/衝突、回復エフェクトと敵ゲスト側の同期、複数補助兵による積算の実戦強さ。

### 1-2. 対空誘導弾（2コスト・飛行への1体狙い撃ち／コンセプト採用済み）

| 項目 | 第1次仮値 |
|---|---|
| コスト／使用上限 | **2／3回**（最大資源6） |
| 指定 | 戦場の任意地点を1タップ。**指定点から半径100内**の対象を選ぶ |
| 主効果 | 範囲内の敵飛行ユニットのうち、指定点へ最も近い**1体**に**160即時ダメージ** |
| 飛行敵が範囲内にいない場合 | 指定点から半径100内の最も近い敵**地上1体に25ダメージ**（手札で完全に腐りにくくする仮案） |
| 対象がどちらもいない場合 | 空振り、資源/回数を消費して手札は進む（既存スペルと同様） |
| 同距離のターゲット | ユニットの安定ID順。**対空優先**：範囲内に飛行が1体でもいれば地上には当たらない |
| 施設への効果 | 砦・城に無効。**範囲ダメージ、スタン、飛行を引き寄せる効果はなし** |
| 演出 | 指定位置から追尾ライン→命中。移動中の命中ずれは起こさない（対象確定後は発動即時ダメージ、演出のみ遅れてよい）。 |

- 現行の飛行敵HP：**浮遊ドローン120・突貫爆撃機150・対地爆撃翼230**。160ならドローン1体と突貫爆撃機を1発で撃破、対地爆撃翼はHP70残る。ドローンは**4コスト1召喚で2体**なので、誘導弾1枚は片方のみ撃破。爆撃翼は2枚必要（単独で無傷の場合）。
- 対地の25ダメージはスペルに絶対的な汎用性能を与えないための退避効果。**地上効果ゼロ（完全対空特化）にすべきかはユーザーとの共同判断項目**。
- 指定点100は効果探索半径であり範囲攻撃ではない。わざわざ移動するミサイルの当たり判定・追跡通信を追加しない。発動の資源と回数は1回だけ差し引く。

### 1-3. 小雷撃（1コスト・小範囲即時攻撃／本人第一候補）

| 項目 | 第1次仮値 |
|---|---|
| コスト／使用上限 | **1／4回**（最大資源4） |
| 発動 | 戦場指定位置へ**即時**、範囲**半径45** |
| 与ダメ | 円内にいる敵ユニットすべてへ**30ダメージ**（地上・飛行とも可） |
| 味方・城・砦 | **ダメージなし**。フレンドリーファイアなし |
| 対象上限・追加効果 | **数による上限なし、スタン・減速・ノックバックなし**。追加ルールを増やさない |
| 空振り | 対象0でも資源1・回数1を消費して手札循環（既存スペルと同様） |
| 戦術 | 瀕死へのトドメ、密集小兵の削り、安いカード循環。範囲の狭さ・微ダメージが弱点 |

- 現行**範囲砲撃**は4コスト/2回/半径82/125ダメージ/1.3秒遅延。**小雷撃**は1コスト/4回/半径45/30ダメージ/**即時**。範囲面積比は`45²/82²≈30.1%`。密集に使えば範囲外よりはるかに得だが、分散には弱い。
- 対1体の素ダメージ効率は`30/1=30/資源` vs 範囲砲撃`125/4=31.25/資源`。これはあくまで素の火力比で、範囲、着弾遅延、HPの撃破閾値は別。**1コストでサイクルを回せること自体が価値**なので、無条件で得するようなら要再評価。
- 4回全部同じ相手に当てれば最大120削れる（各回対象が生存し対象に入る、軽減・回復なしの理論）。実プレイでは手札循環と資源が必要なので瞬間連射前提にしない。

## 2. SOP v1.2 先行ステップ：衛生補助兵の全既存19兵種との数値総当たり

### 数値だけで怪しいと判断したこと（本人と付加価値を検討する前）
1. **衛生補助兵の素の戦闘力は同コスト2種を含め全19種に負ける**。2コスト1体HP180/10ダメ/2秒が、回復の価値に見合うかは未確認。
2. 基本歩兵との**カード単位**：衛生補助兵は7.25秒で倒され、基本歩兵2体が合計HP170残る。**同コストでの直接戦闘は大きな差**。
3. 魔導射手との**カード単位**：6.60秒で倒され、射手側2体が合計HP150残る。射程差を含めると更に違う可能性がある（ここでは抽象化）。
4. カードサイクル・回復の将来価値は殴り合いに直接足さない。20HP/2秒の単体回復は長期戦で強い可能性があり、**素の弱さと支援の過大価値の両方を検証する必要**がある。
5. **大型/高速自爆への即時弱さ**：高火力の既存敵に短時間で倒される。自爆機や地上専用対飛行の架空比較は実戦相性を示さない。
- 追加の強すぎ疑い：HP180は既存魔導射手(95)1体より高いため、安価な支援で味方の攻撃を受けずに回復を何十秒も継続できると高い資源効率になり得る。**実装前に、同一味方へ複数の衛生補助兵を重ねる20×n/2秒を確認**する。

## 3. スペル2枚の実戦HP閾値比較（旧スペルも含めて）

「即時1発・被ダメ軽減/回復なし、指定範囲内」という仮条件。小雷撃はすべての指定内敵ユニット、対空誘導弾は**1体だけ**。表の「残HP」は**その1体**の残HPで、他の同時召喚体は変わらない。

| ユニット | 元HP | 1カード体数 | 飛行/地上 | 小雷撃30後の残HP | 対空誘導弾160/地上25後の残HP | 注記 |
|---|---:|---:|---|---:|---:|---|
| 魔導射手 | 95 | 2 | 地上 | 65 | 70 | 誘導弾の地上時25では1体も倒せない |
| 基本歩兵 | 105 | 2 | 地上 | 75 | 80 | 誘導弾の地上時25では1体も倒せない |
| 浮遊ドローン | 120 | 2 | 飛行 | 90 | 0 | 誘導弾160は2体中1体撃破 |
| 突貫爆撃機 | 150 | 1 | 飛行 | 120 | 0 | 誘導弾160で1体撃破（自爆前なら） |
| 対地爆撃翼 | 230 | 1 | 飛行 | 200 | 70 | 誘導弾1発後HP70、2発目で撃破 |
| 双剣兵 | 145 | 1 | 地上 | 115 | 120 | 誘導弾の地上時25では倒せない |
| 守護ゴーレム | 1300 | 1 | 地上 | 1270 | 1275 | 誘導弾の地上時25は小さな削り |

- 浮遊ドローンは1カードで2体、HP120ずつ：小雷撃を2体が同時に半径45内で受ければ合計**60**削れるが、どちらも生存。対空誘導弾はHP120の1体だけを撃破、もう1体は無傷。
- 突貫爆撃機HP150：対空誘導弾160なら接触自爆前なら**即撃破**できるが、すでに接触した爆発は取り消せない。
- 対地爆撃翼HP230：誘導弾160で70残り、2発命中で撃破。貫通射手HP170（地上）は小雷撃30で140、地上用誘導弾25で145残る。
- 範囲砲撃4コスト/半径82/125/遅延1.3秒は射手HP95/ドローンHP120を一撃で倒せる。ただし飛行を含むかは**現在の実装**を必ず見て確認（`spellStep`は`CLASSES[u.key].flying`を除外していないため、地上・飛行とも対象）。小雷撃は射手HP95を一撃では倒せない。
- 大型への即死は狙わず、単体誘導弾・範囲小雷撃・既存砲撃の役割が重ならないようにした。HP境界（120/150/230）を意図的に跨ぐ160は最優先のバランス検証項目。

## 4. デッキ・枯渇・エネルギーの静的例
- 3枚の有限出撃予算：衛生補助兵`2×4=8`、対空誘導弾`2×3=6`、小雷撃`1×4=4`、合計**18**。
- 現行デフォルト10種の合計予算**113**。そこから魔導射手（10）・防護結界（9）・範囲砲撃（8）をこの3枚に入れ替える例は**113−10−9−8+8+6+4=104**。既存の重複なし10枚/手札4枚/基本歩兵固定の仕組みを維持。デッキに入れる前提とは限らず、あくまで説明用。
- 小雷撃を「4回使い切り」で手札から除外すると1コスト循環カードは永久に回らない。対空誘導弾は飛行がいなくても小さい地上効果があれば最低限の用途がある。**手札内の任意捨て札や無料交換は今回追加しない**。
- 新カードのコスト・最大回数は全て**仮値**。本人が一つだけ修正した場合、残りを自動的に正式仕様と見なさない（ただし本人が「ほかは採用」と明示した場合は従う）。

## 5. 実装する場合の最小仕様・検証計画（未着手）
- 同じ共有カタログ・デッキ・残数HUDへカードを追加。衛生補助兵は共有guard行動＋独立の定期回復処理のみ、回復値は単独定義・対象ソートは安定IDで決定。独自のターゲットAI全書き換えなし。
- 対空誘導弾・小雷撃は既存`castSpell`で効果分岐、`hitUnit`で既存ダメージ軽減を適用し、味方・建物に命中させない。キャラ死亡判定は既存フローを利用。位置はホスト側で判定しゲストへ通常スナップショットを同期。Firebase Rules変更なし。
- 弾の追尾や持続時間をネットワーク権威化する新システムは作らない。見た目だけで飛ぶ弾を演出する。新カードにはカード絵/戦闘絵/発動演出も追加し、古いアイコンを流用しただけで完了としない。
- 部隊がいる/いない、飛行優先、複数飛行、地上fallback、範囲45、砦/首都ダメージなし、回復不可対象、HP上限、同時回復複数、場外/正しい手札循環、BOT/ゲスト/再戦/単体HTML一致をテスト。ゲーム画面実レンダリングとiPad Safariは実装後に別に確認する。
- 旧カードの上限、対地爆撃翼2、貫通射手4、引力飛行無効、迎撃行動と新マリガン20秒/10秒準備は変更しない。
