## 1. 本ゲームの固有制約

- 試合5分300秒、初期資源8、100秒まで0.25/s、210秒まで0.36/s、270秒まで0.53/s、以後0.7/s、自然回復107.4、初期を加えた理論最大115.4。資源上限12による溢れ・未使用・早期決着・準備時間中の出撃などは理論値に含めない。
- プレイヤーのデッキは10種類の異なるカード、手札4枚を使用ごとに循環。基本歩兵はデッキ外固定で無制限（1回コスト2、2体召喚）。
- `limit` は**1試合中の召喚操作回数／スペル発動回数**。`qty:2` の魔導射手・浮遊ドローンは1使用で2体。城ドラの「召喚数（体数）」と混同しない。
- あるカードの残数が0になると手札循環から除外される。試合終盤にすべてを早々に使い切ると基本歩兵のみになるため、極端な一律制限はしない。
- `S.units` の各チーム65体同時存在上限は別の制約であり、この設計では**変更しない**。
- 遠距離工兵・貫通射手は対空、制圧機兵/戦車の対空爆風、引力が飛行対象外、突貫爆撃機の最近の試遊用強化、浮遊ドローン速度の暫定34→30など既存仕様を保持。AIを変更しない。

## 2. 設計の評価軸

1. 総量：各10枠の`Σ(cost×limit)`が総資源115.4前後に収まるか。ただし基本歩兵を使用する分、資源上限12で溢れる分があるので、厳密な等号や固定上限は設けない。
2. 使い切り：頻出の主力は3～5回、強い能力を持つ兵・大型は2～3回程度をまず仮置きし、**同じカードを連続使用した場合には終盤の不足が現実的に起こる**設計を狙う。
3. 役割：反撃・対空・砦占領など他に代替手段が少ない役割を全部一律に制限せず、代わりのカードを選ぶ余地を残す。
4. 複数同時召喚：`qty:2`は上限1で2体と数える。子ユニットを生成する機械召喚師は1召喚につき生存時最大8小型機の可能性に注意。
5. 戦術：短期決着を狙って低出撃予算で組む構成を禁止しない。高出撃予算が常に強いわけでもない。「高予算＝正解」とは扱わない。
6. 素のHP/攻撃力/攻撃間隔に踏み込むバランス変更は`UNIT_BALANCE_WORKFLOW_STANDARD.md`の本人共同評価手順に従い、今回のlimit検討に勝手に混ぜない。

## 5. 定量チェック（資源容量の静的分析）

`出撃予算 = Σ(各デッキカードのcost×limit)`、基本歩兵除外。

- 現行デフォルト10枚（scout, engineer, archer, barrage, sentinel, suppress, guardian, ward, drone, tank）：現行 **170** → 新提案 **113**。57減＝**33.5%減**。
- 本ゲームの5分間総資源理論最大**115.4**。基本歩兵を10～20資源分使う想定なら、その他カードの利用可能資源は**95.4～105.4**。新提案113と比較して7.6～17.6の余裕があるが、手札/エネルギー上限などの非効率もあり実戦の欠品タイミングは未知。
- 現在のデッキプールは基本歩兵を除く**22種類から重複なし10枚**。この第1次案で可能な全`C(22,10)=646,646`通りを**予算だけ**で網羅計算すると、**最小93・最大135・中央値115**。5パーセンタイル105、95パーセンタイル124。93や135は極端な構成なので、予算を固定値にするための自動制限は付けない。
- 実例：低コスト中心の10枚（archer, gravity, piercer, ward, gale, scout, duelist, interceptor, barrage, engineer）は**99**。高コスト中心10枚（catapult, guardian, tank, kaiju, ground_bomber, suppress, crusher, mech_summoner, kamikaze, engineer）は**129**。
- **注意**：`cost×limit`は「全部使い切るのに必要な資源」＝デッキの持久力であり、カードの強さや実際の勝率を直接表すスコアではない。回復の無駄・打ち止め・守備/攻勢・召喚位置・カードの引き順等で実際の消費量は変わる。

## 6. 現時点で考えられる主要リスク／特に本人に見てほしい値

1. **制圧機兵6→2**：現在の対空・範囲の主力として実際の友達対戦で使用頻度が高い場合、2回は少なすぎるかもしれない。候補3回（出撃予算15）への緩和可能。
2. **貫通射手5→3**：射程と対空で便利だが耐久170。対空の代替手段が少ないデッキなら4回に緩和を検討。
3. **範囲砲撃・引力3→2**：スペルが循環から消えることで、終盤の逆転力が減る可能性。現行3維持も選択肢。
4. **魔導射手8→5（2体/回）**：最大16体→10体になるが、唯一の対空ではない。他のデッキカードで補えるかが重要。
5. **突貫爆撃機4維持**：火力400への強化は直近の試遊用のため、最終的な体感バランス未確認。先に強化の評価が必要。
6. **特殊なデッキ最小93**：理想的にカードへ資源を使い切ると早めに基本歩兵だけになり得る。短期決戦型の選択として許すか、特定の上限を少し上げるかは試遊で判断。
