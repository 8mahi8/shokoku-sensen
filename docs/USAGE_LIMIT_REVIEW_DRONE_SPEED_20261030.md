# 小国戦線III｜使用回数上限の見直し・浮遊ドローン速度試遊値（2026-10-30）

## 最新の本人依頼
- 新キャラ追加前に、現状ほぼ機能していない「キャラ上限」（各カードの1試合使用回数）を議論したい。**上限変更の承認はまだない**。
- 浮遊ドローンの移動速度を「ちょっと下げてほしい」。数値指定なしのため、AIによる控えめな**試遊用暫定案 34→30（約11.8%減）**を開発ブランチだけに適用。他の数値・既存AI・カード使用制限は維持。正式バランス確定ではない。

## 現行コード確認
- 戦闘時間300秒、初期エネルギー8、最大12。回復量は時間0–100s=0.25/s、100–210s=0.36/s、210–270s=0.53/s、270–300s=0.7/s。
- 5分間の最大自然回復は100×0.25+110×0.36+60×0.53+30×0.7=107.4、初期8を含め115.4（自然回復の溢れ・実際の資源未使用は無視した理論上限）。
- 例：平均4コストの出撃に全量を使えた場合、約28.85回。デッキは10種、常時枠の基本歩兵を除いて4枚手札が循環。通常カード4～6回の上限は、個々のカードを特に集中的に回さない限り触れにくいと推測する。**本番プレイの使用回数実測ではない**。
- 現在はカードを使って回数0になった時、そのカードは山札に戻らない。残数は戦闘HUDで表示。低い上限を大量のカードへ安易に設定すると、デッキの選択肢や後半の手札数が減る可能性。
- 無制限=基本歩兵。中型・小型の多くは4～8回、ゴーレム/戦車/怪獣が2回、投石器3回。各スペル3回。別仕様として1陣営同時生存65体制限がある。これは今回の使用回数議論と混同しない。

## これからの設計案（未承認・コード変更なし）
A. 通常ユニットは原則無制限、強力な大型・召喚師など特徴的なカードとスペルだけ限定回数。例外カードの希少性は維持するが、「通常キャラが上限に到達しないだけ」の無意味な表示を減らせる。第一推奨案。
B. 既存の上限をそのまま維持。変化が少なく安全だが、「上限が空気」なのは継続。
C. 一律2〜3回まで大きく下げ、資源以外の希少性を強くする。ただしカード消滅・手札減少の影響が大きく、10枚サイクルのテンポが変わるため拙速に採用しない。
- 本人と目的（希少性／戦術性／単なる不要仕様の整理）を相談したあと確定する。承認前に限度値・消耗時のUIを変更しない。
- 調整したらオンライン二席・ソロBOT・マリガン・再戦・最後の残カード切れを重点的に試験。
